# 设计任务：Nexion 运营后台「客服中心」全新设计

> 用途：喂给 Claude design  做域 M「客服中心」(M1–M5)的全新视觉与排版设计。
> 原则：本 brief 只描述「要干什么、呈现什么数据、有哪些动作、给谁用、在什么介质」——**排版 / 分栏 / 视觉 / 组件 / 交互全部交给设计师思考**,不预设方案。

---

## 角色

你是顶尖 B 端运营工具设计师 + 前端原型师。为一个内部运营控制台的「客服中心」做**全新设计**——**排版、信息架构、视觉语言、组件、交互全部由你思考**。产出 **5 页可交互 HTML 高保真原型**(真数据渲染、桌面端、深色),先给一段你的设计概念说明,再给五页。

## 这是什么 / 给谁用(定义问题,不规定方案)

- **Nexion 运营控制台**——平台**内部运营人员**用的后台系统,**不面向终端用户**。其中「客服中心」是把异步**工单**和即时**人工会话**重组成的独立坐席工作域。
- 使用者 = **客服坐席 / 客服主管 / 风控**。他们整天在这里**扫队列 → 进对话 → 回复 / 处置**。
- 介质：**桌面端、深色、信息密集、专业**。中文界面;技术标识(路由、key、分类码)是次要信息。**中性运营语言**——这是严肃的内部工具,**绝不能有任何营销 / 促销 / 口语化 / FOMO 文案**。
- 设计目标:让它**像个真正的客服运营系统**(气质可参考 Zendesk Agent Workspace / Intercom Inbox / Front / Linear,但你自由重新诠释),核心是**坐席效率**——快速分诊、状态一眼可辨、回复零摩擦。**别做成通用后台的表格堆。**

## 五页:各自要干什么(只给意图 + 数据 + 动作,排版你定)

**M1 客服总览** — 让主管 / 坐席进来几秒看清整个客服盘的健康度,并一键进两个台。需呈现:进行中工单、待用户补充、进行中会话、待坐席回复的实时计数;各工单分类的 SLA 达成 / 超时风险;坐席负载(谁忙谁闲——派生自各人手上的开放工单 + 会话数,非真在线态)。**全只读派生**。用卡、表、图、环还是别的随你。

**M2 工单台** — 坐席处理**异步工单**的工作台。要能:浏览一个可按状态 / 分类筛选、可搜索、可分页的工单队列;选中一单看它全部上下文(主题、分类、状态、优先级、时间线、完整消息往来);在该单上**回复**(可用快捷回复模板)、改 owner / 优先级 / 状态、关闭 / 重开、以及**升级为即时会话**。**已解决 / 已关闭的工单可一键归档**——归档不是删除,而是从活跃队列移进一个**可查询的「已归档」类别**(能按归档态筛选 / 搜索把旧单翻回来核查,归档可逆)。注:例行的回复 / 分配 / 改状态 / 关闭 / 归档 = 直接执行 + 自动留档(**无需填理由**);只有"升级为即时会话"这种跨载体处置才弹**确认 + 理由**。

**M3 即时会话台**(客服域的灵魂页)— 坐席**实时接待**用户即时会话。要能:浏览可筛选 / 搜索 / 分页的会话队列(谁未读、谁在等回复;**已结束的会话同样可一键归档进可查询的「已归档」类别**);进入一个会话看完整对话(用户与坐席往来——顾问类会话里坐席的主动话术会带转化 CTA,如「→商城」「→锁仓」);**回复**、改 owner / 状态、把会话**转工单**;还能**主动发起会话**。发起时有两个要点:① **目标二选一**——既能精确指向**单个用户**(按用户 ID / 检索定位某个人),也能**圈定一类人群**(按画像投放),两种都要支持,**不是只能圈群体**;② **以哪个身份发出由坐席选**——一个坐席账号下可挂**多个身份 ID**(若干**客服身份** + 若干**顾问身份**,各有展示名),发起会话时挑用其中一个(决定这条会话以客服还是顾问、具体哪个身份呈现给用户)。体验上:坐席切到别的页面再回来,要能**续上**刚才那个会话(持续接待感)。

**M4 知识库与 SLA**(配置面)— 维护 Help / FAQ 内容(新增、发布)+ 工单分类的 **SLA 矩阵**(每个分类的首响目标、解决目标、负责队列、升级路径,可编辑)。

**M5 话术与模板配置**(配置面)— 开关会话类别(专属顾问 / 普通客服;Nova AI 由别处管,这里只读展示);配置顾问**主动推送策略**(主动推送总开关 / 首推延迟 / 冷却 / 单会话上限 / **受众圈定**);维护顾问**主动话术库**(分类 / 文案 / CTA / 受众 / 发布态)和**即时回复模板库**;并维护**坐席身份库**——每个坐席账号可建立**多个身份 ID**(分**客服身份** / **顾问身份**,各有展示名与启用态),供 M3 发起会话时挑选以哪个身份对外。这些是高敏配置动作,带**确认 + 理由**(视觉上可比例行动作"更重")。
