# 业绩榜标识、下拉及按钮验收

本批为既有界面样式修正，不修改业绩口径、权限、数据读取或客户消息链。功能 PRD 保持原契约；整幅设计稿像素验收仍未通过。

## 当前结果

- 姓名和组名使用同一个可缩窄区域；“我”及升降标识占单元格尾列，跨两行垂直居中。1536、1000、390 三种宽度，普通、长名称/长组名、未知三类状态共45行：无页面横向溢出，姓名/组名与标识至少12px，行中心误差不超过0.167px。长内容省略且原完整名称提示仍在。
- 币种、月份、范围和每页条数四处下拉保留原生选择语义；当前浏览器使用主题化选项及锚定菜单。两种宽度共8个实际展开：选项14px、至少36px高、长项换行、菜单在屏幕内，底部分页菜单可向上避让。四项方向键/Enter选择与Esc返回焦点通过，月份禁用项被跳过。
- 分页由左侧记录总数、右侧条数与翻页组构成。条数框与翻页组相距20px且垂直居中，不再保留旧截图中悬在中间的固定坐标。
- “定位我”为112×36、14px文字、16px图标；触屏粗指针为44px高。实际点击仍将焦点交给表格。保留悬停、按下和可见键盘焦点样式。
- 浏览器无页面错误；验收结束恢复正常动效。新增浏览器断言进入现有运行脚本；本批通过CUA执行最小等价步骤，没有重复整套榜单业务矩阵或创建新测试库。无损像素输入及既有背景11项定向测试通过，运行脚本语法检查通过。

## 边界与六维复核

1. 真落地：共享CSS实际加载、页面重载后仍生效；本批不新增持久化写操作。
2. 完整性：姓名、组名、本人标识、变化说明、全部数字、翻页、条数与定位入口保留。
3. 交互：四类菜单实际选值/禁用/Esc，定位点击与焦点已核验；既有权限和回调未改。
4. 同形：所有表格行与四个共同下拉实例均覆盖，未用单行截图代替同类检查。
5. 不变量：原双币和指标契约未改，长文、未知、窄屏及触屏尺寸有相应证据。
6. 实景：组件截图、DOM几何、交互及独立复核单列；整体客服中心仍按[总验收记录](support-center-handoff-20261014.md)保留未签项。

未验证不支持 `base-select` 的旧浏览器主题化菜单；它们保留原生选择回退，不宣称外观完全一致。本批不重跑资金与真实消息链，不代签整页像素或未齐的真实榜单基线。仅真实客户消息链交给同事，其余未签项仍由当前任务继续处理。
