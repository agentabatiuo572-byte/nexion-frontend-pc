# H9 首页数字展示（2026-10-25）

现行 PRD 见 [FEAT-APP-20261025](PRD/specs/FEAT-APP-20261025-experience-alignment.md)。H9 将两项当前值和各自增长区间集中在“首页数字增长”独立板块，开关与状态就在同一板块头部。

用户指定介绍页在线设备从 28,432 开始，每秒增加 1–3；累计已发放从 $130,532 开始，每秒增加 $1.10–5.50。默认暂停，只有点击开启并确认才开始增长。暂停保存当时数值，恢复继续增长；普通保存不隐式开启。

| 字段 | 合法域 | 初始值 |
|---|---|---|
| `H.publicStats.homeOnlineCurrent` | [0, 9000000000000]，整数 | 28432 |
| `H.publicStats.homeOnlineStepMin` | [0, 1000000]，整数 | 1 |
| `H.publicStats.homeOnlineStepMax` | [0, 1000000]，整数 | 3 |
| `H.publicStats.homePaidCurrent` | [0, 9000000000000]，最多两位小数 | 130532 |
| `H.publicStats.homePaidStepMin` | [0, 1000000]，最多两位小数 | 1.10 |
| `H.publicStats.homePaidStepMax` | [0, 1000000]，最多两位小数 | 5.50 |

两个区间均要求最小值不大于最大值。到上限停止增加。

后端每分钟扩展一次全平台共享的随机批次，真实随机、不固定种子。批次持久化数据库，Redis 缓存 60 秒；H9 修改与生成批次使用同一版本行锁。客户端只拉取公开的批次和服务端时间，不接受用户写入；每 60 秒刷新，页面隐藏停止本地更新，返回立即重新拉取。状态修改最多 60 秒同步到已打开页面。查询失败显示占位，不继续播放旧批次。

长时间后端停机超过预生成窗口时，恢复从最后持久数值继续，不补造停机期间的随机增量。两个数字仅用于首页展示，不改变真实设备、账单、余额、奖励或统计报表。

本补充替代旧规格中介绍页从设备日产锚推导支付额的规则；历史参数仍保留兼容，其余业务统计不受影响。批次接口为 `/api/config/home-display`，金额以整数分传输。
