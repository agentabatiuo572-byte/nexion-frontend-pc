# 客户端专属顾问私聊：手机视觉与交互交接

设计输入为 `mobile-chat-final-v2.png`；`mobile-chat-final-v1.png` 仅保留生成历史。**一张画布的三台手机代表三种单独的运行状态，不是在同一客户端同时显示三列。**本文件是 S6 的视觉交接，不是已上线能力或客户端实施授权。功能与权限以 S1 `docs/specs/support-redesign-20260929/CONTRACTS.md`、`OWNER-DECISIONS.md` 为准；现有 `src/pages/support/chat.vue` 的独立全屏头部、`src/components/support/conversation-thread.vue` 的消息列表与底部输入区、`src/styles/tokens.css` 的双主题 V5 token 是还原基线。后台五图只给客服品牌关系作参考，手机不移植后台三列。

## 三屏及点击流

| 状态 | 要显示什么 | 点击后的真实结果与出口 |
|---|---|---|
| 已绑定私聊（左） | 当前**唯一**专属顾问、是否在线、原顾问离线仍保留留言；客户/顾问文字分侧，图片缩略图、时间/作者，底部图片入口和输入区 | 点击图片打开可缩放大图，关闭后返回原滚动位置。文字发送成功须服务端读回，失败保留草稿和重试；图片先上传到私有暂存，再由用户明确发送消息，上传成功不等于发信成功。返回会话列表保留输入草稿。 |
| 等待分配（中） | “尚未分配顾问”、客户已提交的留言及收到确认，不能假冒某位顾问回复 | 客户仍可留言；成功后显示“留言已收到，等待分配后由专属顾问接续”。顾问忙碌/离线不触发改派。分配完成后刷新并展示服务端当前顾问，历史消息保留真实作者。 |
| 图片失败恢复（右） | **上传失败的附件草稿**和**发送失败的消息**分成两块；前者“重试上传/取消附件”，后者“重试发送/放弃草稿” | 上传重试成功只变为待发送附件，必须再点发送；取消附件只清该暂存。失败消息以同一消息意图查询结果并幂等重试，不产生重复消息。若无法确认服务端是否提交，先查询命令结果，不能将“放弃”解释成撤回已送达消息。关闭/返回须保留未解决草稿或提示。 |

### 独立审查后的图片硬性勘误

1. 左、中图输入为空且无就绪附件，“发送”被画成亮蓝；**实际必须置灰并禁用**。只有非空合法文字或已就绪图片可发；上传失败附件单独存在时发送禁用。右图的禁用样式才是空输入参照。
2. 左图的设置截图缩略图未画清“查看大图”提示；实现要让整张缩略图可点、可键盘操作，提供可见“查看图片”说明，打开可关闭的大图层。不可把缩略图的小字当成唯一可读内容。
3. 右图失败文字“这张设置截图里……”会误导为上传失败的图片已随消息发出。**生产示例改为不引用失败图片的中性问题**，并在失败附件旁显示“未附加到消息”；文字重试只重试原文字消息。若草稿确实意图携图，先成功上传并让客户再次确认整条消息后才发送。
4. 右图的失败消息仅画“重试发送”，须补“放弃草稿/返回编辑”出口；放弃前按命令结果确认未送达，错误与重试次数可读。上传卡已有“取消附件”，两条失败路径互不代替。
5. 中图服务确认里的“尽快”为生图示例，正式文案用“留言已收到，等待分配后由专属顾问接续”，不承诺未批准的时限。右图“请检查网络”不能预判失败根因，正式提示按服务端结果给出可操作原因，未知时写“上传失败，请重试”。

## 必要状态与权限

| 状态 | 手机端可见行为 |
|---|---|
| 初次加载 / 刷新 | 保留独立全屏页状态栏、头部和底部安全区；显示消息骨架和“正在加载”，不闪现其他顾问或空会话结论。加载失败显示重试和返回。 |
| 空会话 | 已绑定时提示“还没有消息，可以给当前顾问留言”；未绑定时提示“暂未分配顾问，可以先留言”。输入与按钮仍遵守可用性；无假消息 seed。 |
| 顾问离线 / 忙碌 | 显示真实当前归属和“可留言等待回复”；不出现“换一位顾问”“智能转接”“临时代班”或客服身份选择。 |
| 顾问账号停用 | 与普通离线区分，显示“当前顾问暂不可服务，留言会保留”；消息仍留原客户收件箱，等待主管正式转绑后由新顾问接续。不得暗中改派、假装原顾问可回复或暴露内部停用代码。 |
| 网络/存储不可用 | 文字和图片分别显示发送、上传阶段与失败原因；可重试、取消/返回；草稿不丢。上传完成后发信失败仍保留就绪附件及原消息意图，不伪造已送达。 |
| 登录失效 / 无权访问 | 停止显示私聊正文和私有图片，清理内存图片对象 URL/缓存；提供重新登录或返回。不能从客户端传别人的 customerId 冒用。 |
| 正式转绑 | 从服务端刷新**当前**顾问；旧顾问不再可见为当前身份，旧消息保留原作者/时间。撤销旧会话订阅和受限图片缓存后按新权限重取；无历史代发。 |
| 停止主动维护 | 不改变私聊入口、顾问归属或客户主动求助权；不显示“无法联系顾问”。 |

本期仅文字与静态图片。图里的省略号菜单不能提供顾问/客服角色切换、语音、视频或 Nova AI；不显示规则 D/M/W/L、继承算法、价格或营销内容。图片缩略图、头像、顾问姓名、消息与时间都是示例。页面文案按现有 zh/en/vi 资源同步，不把中文写死在其他语言端。H5 与 APP 共用状态契约，安全区、键盘弹出、图片选择/预览按各端能力适配；授权与实际发送结果始终以服务端为准。
