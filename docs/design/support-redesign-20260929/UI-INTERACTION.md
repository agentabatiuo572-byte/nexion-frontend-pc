## 点击流与业务语义

| 入口 → 操作 | 可见结果与失败出口 |
|---|---|
| 工作台待办 → 回复/联系客户 | 打开该客户当前归属会话；同一客户多种待办只占一行，可同时显示多个标签。已读不消除待顾问回复；顾问**成功发出**覆盖相应客户消息后才清待回复。 |
| 客户详情 → 联系客户 → 选择“联系维护”意图 → 成功发送 | 服务端提交人工消息及维护执行后刷新执行记录；普通服务回复、失败发送、图片仅上传成功、点击按钮均不计维护执行。之后仅新的有效账户活动可使开放周期成功。 |
| 客户详情 → 不再维护 | 打开写明对象、影响和必填理由的确认框；提交成功后显示“暂停主动维护”，从主动待办移除，保留顾问归属、私聊与客户主动求助。失败保留理由与抽屉，提供重试/取消。 |
| 已暂停客户 → 恢复维护 | 独立入口与确认/理由；恢复后重新按当前规则计算到期，不复活旧周期，不自动生成执行或成功。停止期间客户活跃只更新活动状态，不追认旧维护成功。 |
| 主管池 → 行分配 / 勾选后批量分配 | 抽屉列出**精确客户 ID**、目标顾问绑定人数与会话负载、必填原因；提交前确认范围。每位选中客户新开继承段 0 层，未选中客户不变；版本冲突保留勾选，刷新预览后再确认。无顾问忙碌/离线自动改派。 |
| 主管审阅 → 正式转绑 | 默认只选当前客户；若选后代，先列实际 ID 和旧→新顾问。旧顾问立即失去消息/附件读写，新顾问可看必要历史并重新收到首次联系提醒。不能在会话菜单里临时代班或冒名发送。 |
| 超管规则 → 编辑 → 影响预览 → 理由确认 | 未配置显示“未配置”，不能作为 0 使用；**允许有效的部分配置保存**，无变更不可提交。仅已修改字段通过自身校验、版本未冲突且理由填写后确认可用；D/W 同时配置时才检查 W≤D，有限层数模式必须填写 L。确认页逐字段显示旧→新值与仍不可用的能力；D/M/W 仅重算各自可用的标签或统计，L 仅影响新注册，既有归属和待绑定池不自动重排。 |

### 图片校正清单（实施时必须按契约）

- 工作台六指标可能重叠，**不能相加**。`待维护 16` 与筛选 chip 已同口径；待办“全部 24”是按客户去重的并集，每行必须显示入待办原因，沉睡标签本身不产生待办。`已执行维护 42` 是成功持久化的执行**次数**，`已重新活跃 12 个周期 / 11 位客户` 分别是成功周期数与去重成功客户数，时间区间在真实页面必须可见。
- “活跃客户”展示当前配置的 W 天窗口，账户“活跃/沉睡/未知”按 D 与活动数据完整性判定；W 和 D 是不同规则。客户列表每行显示账户状态和维护状态两个维度，缺数据写“未知/未配置”，不能空白当正常。
- 客户列表图中“恢复维护”展示在暂停客户行；同动作也须出现在该客户详情。右侧 B002 的“沉睡”是账户状态，“正常跟进”是维护状态，可并存。
- 会话图里营销活动对话、头像、数字、左列未读小圆点都是占位示例；实现用真实授权消息。待谁回应按**最后成功发送**及回复游标判断，失败消息不改变状态；已读和待回复分开。会话状态与维护状态独立。文字为空且只有上传失败附件时“发送”禁用；输入文字后可只发送文字，须先移除失败附件或明确告知不会随信发出。
- 主管池图的表头复选框画成全选、而只有两行勾选；**实现必须用半选态**，并在确认框逐个显示实际选中 ID。图里理由为空时绿色确认按钮仅为视觉偏差，真实按钮必须禁用并提示理由 8–200 字；输入错误保留范围、理由和取消出口。
- 规则图展示“所有字段均未配置且无变更时确认禁用”的状态，**不能推导出四项全填才可保存**；M 单独配置也应可保存并产生相应待维护能力。D/M/W 各自可为未配置或正整数；W 与 D 同时配置才检查 W≤D。L 的“未配置”“不限制”“有限层数”三态须明确区分，有限层数为非负整数。图中没有任何默认生产天数。图中“最大层数”的解释方向有误，实际文案应为：**“从人工分配的客户起点 0 层开始，其后续邀请注册可向下继承的最大层数。”**
- 规则图右上“当前为超管视图”只是登录身份的静态标识，不能通过下拉切换身份或获得编辑权限。主管只读时四项字段、开关与保存均不可操作，显示“仅超管可修改服务规则”；普通客服没有配置入口。

## 四态、权限与窄屏

| 页面 | 默认 / 空 | 加载 / 错误 | 权限 / 窄屏 |
|---|---|---|---|
| 工作台 | 六指标带统计时间和规则可用性；无本人客户时给“查看待绑定状态/等待主管分配”说明，未配置值为 `—·未配置`，未知活动单列 | 骨架和上次更新时刻；失败显示“暂无法同步”+重试，绝不把失败当 0 | 普通客服只见本人；主管只读审阅。窄屏卡片两列/单列，待办变卡片，动作保持可见。 |
| 我的客户 | 空列表给清除筛选；详情无联系史写“尚无人工联系”，未知活动写“数据待核对” | 搜索/分页保留；停止/恢复提交中锁按钮，冲突或失权时关闭敏感详情并刷新 | 仅当前顾问操作停止/恢复；主管审阅不代办。窄屏全屏详情，返回保留搜索与滚动。 |
| 会话 | 无会话时提示等待客户留言或从本人客户发起；输入与上传入口状态明确 | 消息/图片各自独立失败重试，保留草稿；401重新登录，403/404失权退出，断线显示重连与重试 | 主管仅审阅不能冒名发信；转绑旧顾问立刻撤销会话/附件。窄屏列表→对话→资料逐层进入并可返回，发送控件固定可达。 |
| 主管池 | 空池写“当前没有待分配客户”；空选择不启用批量，单客与批量明确不同范围 | 加载锁选择；409 保留选择并要求刷新预览，503 不伪造成功 | 普通客服不见分配控件；主管可分配。窄屏表格改每客户卡片，选择数量和确认范围始终可见。 |
| 服务规则 | D/M/W/L 可分别“未配置”，逐项说明相关统计/自动判定是否可用；L 不限制是明确开关，不等于空 | 读失败不允许保存；有效部分配置可保存，无变更禁用；提交中锁输入；版本冲突显示新旧差异并重审，失败保留草稿 | 超管编辑、主管只读且明确原因、普通客服无配置入口。窄屏表单单列，确认框滚动可读且取消/确认始终可达。 |

所有可点控件需键盘可达、有可见焦点、足够点击面积；drawer/确认框有明确关闭和返回，错误靠文字说明。详情和列表不暴露年龄、性别、城市、财富画像及内部字段名。客户端只同步顾问归属/待分配状态、文字图片私聊和失败恢复；客户端离线时显示等待原顾问，不提供“换客服”入口。客户端无关页面和网站不在本设计范围。
