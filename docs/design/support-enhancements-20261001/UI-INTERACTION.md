## 已确认边界

- P01：策略只自动处理之后新进入的真正无顾问客户。历史池须实际名单预览、理由和明确批量随机确认；自动模式产生的新无候选记录可追踪重试，不暗批历史池。
- P02：超层随机可再次抽到邀请人的原顾问；新继承段 root=本人、depth=0；已有下级不改归属。有效邀请继承优先。已绑定离线/停用不是无顾问，停用交接走正式转绑。
- P03：全部成功充值实际入账额；退款另列。全部成功提现本金；费用、实际到账、处理中独立。按现有资产 USDT/NEX 分列，不跨币种相加。源码依据 `lib/admin/user360-client.ts` 的 User360LedgerRecord.asset，不引入 CNY。
- D01–D06：一项分配单选；本人顾问独占发送，主管审阅不能代发；人工群发普通联系/联系维护明确分开，两类主动群发均排除不再维护；成功保存维护消息才计执行，随后新有效活动才计维护成功；360 本人范围，原动作权限保留，转绑撤权；旧有效能力只增不减、KYC 仍退役、无临时代班；顾问头像由超管创建/修改，历史作者不变。
- S1 补充：未处理客户消息阻断关闭、归档（含批量）及转工单，未读与待处理分别判断；归档不改变会话状态，撤销已关闭会话的归档仍不能发信。头像创建可选，已选图必须上传就绪；头像单独更新保留用户名、显示名、邮箱、角色与其它账号资料。

## 会话与完整资料

| 信息 / 旧能力 | 位置与契约 |
|---|---|
| 身份 | 客户头像、昵称、客户业务编码、内部 ID、等级；顾问姓名/真实头像。历史作者按当时身份，不随当前顾问或头像替换改作者。 |
| 基础联系 | 脱敏手机号、地区、注册、最近登录、有效活动时间分别命名。客户端不得看到内部 ID/备注/风险。 |
| 风险 | 可信等级、客服可读说明；缺值“未知”，子接口失败“读取失败”；专项细节无权限单列，不凭账户状态算假风险分。 |
| 全历史资金 | 分资产累计成功充值实际入账、成功提现本金、退款、手续费、实际到账、处理中、余额；不从近期 20/30 条求和。 |
| 近期流水 / 设备 | 流水独立分页与状态；设备持有、在网、算力、闲置；设备读取失败保留错误与重试，不等于无设备或 0。 |
| 标签 / 内部备注 | 系统标签只读，自定义标签增删；备注作者/时间、增删，沿用原动作资格。主管审阅不自动获得编辑权；原型只本地预览，不写服务。 |
| 服务/维护新资料 | 当前顾问、会话状态、账户活跃/沉睡/未知、维护启用/停止、有效活动、下次维护、首次联系、最近服务、执行次数/成功周期/成功客户，各自独立。 |
| 资料入口 | 本人范围 360、当前客户历史会话、关联工单及数量；密码重置、账户/资金操作进入既有授权模块。原型给目标说明和资料视图，生产必须真正到达授权模块。 |
| 列表 / 归档 | 未读、进行中、已结束、归档计数/搜索/分页、来源和接待身份；单客与批量归档、撤销，不删除历史、不清待回复、不改顾问。 |
| 接待 | 本人客户主动发起、各客独立草稿、切页续聊、历史接续；关闭、归档（含批量）、转工单须无待处理客户消息。关闭段不追加，撤销归档不重开；新段仍归原顾问。转工单另受对象权限，静默超时不得暗换顾问。 |
| 内容工具 | 普通回复模板+顾问话术均保留搜索、分组、数量、已发布状态、点选插入光标且保留原草稿；真实 SKU 名称/编号、下架过滤、加载/空/失败；当前有效商城/锁仓/创世跳转，历史停用入口只读说明。 |
| 消息反馈 | 作者/头像、连续分组、时间、真实已保存/送达/阅读状态分别取真实信号；无信号未知，成功落库不冒称已读。未读不等于待回复，维护发送不自动覆盖待回复。 |

原型用四组 details 可折叠，全部信息实际在 DOM；窄屏资料可单层滚动。相关组件读取失败只显示自身错误，不把成功资金/身份也清空；上次更新时间与数据完整性由可信响应提供。

## 四态与平台矩阵

| 面 | 默认 / 空状态 | 加载 / 报错 | 权限 / 极限 |
|---|---|---|---|
| 会话 | 全资料、消息、工具；无会话引导本人主动联系 | 按列骨架；列表/消息/头像/资金/设备独立错误+重试，保存搜索/草稿 | 主管只读，不代发；转绑立即退出；长昵称/编码/金额换行不遮按钮；0、未知、无权限、失败四态明确。 |
| 群发 | 本人选择和用途；空筛选给清除入口，0选不可继续 | 分页骨架；批次结果逐客显示，失败和未知分开 | 不再维护禁选；筛选跨页不暗扩；顾问失效或转绑跳过，部分取消不整体撤回。 |
