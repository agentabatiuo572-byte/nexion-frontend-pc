# D1 自动资金流程名称调整

用户在 2026-11-09 明确指定将「自动归集」改为「自动归集到cregis」，将「自动甲方付款」改为「cregis转平台收款钱包」。同一自动流程卡的标题、状态、地址角色、提案确认与任务阶段同步使用这些名称；嵌入式与独立式共用实现。人工 BEP20 准备单不属于此次自动流程改名范围。

设计依据：`app/globals.css` V5 双主题 token 与 `app/components/domain-views/d-domain.css` 既有资金域卡片、绿色分网选中态、地址事实、左右操作分组及任务空态。本次不修改样式或布局。

`design.png` 使用内置生图工具，在原三网设计稿基础上生成。提示要求保留卡片结构，替换上述两个完整名称；标题、状态、流程和地址角色一致，示意地址采用占位，运行总开关关闭、两个选项及提交提案禁用。生成图的字体比例、地址行边框和提示色仅为示意，实际沿用现有资金域 token 和组件，不额外改变主题样式。

资金流仍为充值子地址 → Cregis 管理的归集钱包（充值毛额）→ 平台收款钱包（用户入账净额）。`platformAddress` 仍是归集钱包/转出来源，`counterpartyAddress` 仍是原收款地址；只改显示名称，不更换地址或接口字段，不开启运行总开关及自动策略。

验收：构建后发布 TEST，实际全页重载、三网切换和刷新，核对名称、地址角色、BNB/ETH/TRX 与禁用状态；打开暂停确认框检查新文案后取消。两名独立 Agent 对照设计、规范与实景评分，记录在本次 PRD 补充项中。此项不进行真实转账验收。
