# 排行榜公共统计期

同一列共用的统计月份放在列标题正下方；普通行不重复日期。本补充沿用已确认的横向排行榜、绑定客户数和紧凑数值展示，不改变数据口径、权限、排序或榜单计算。

## 展示与一致性

业绩额、首充人数列的副标题显示当前榜单实际统计月份。规模榜两列显示当前月份并标明“参考”，不沿用隐藏的历史月份筛选。绑定客户数保持“截至现在”。

普通金额行只显示金额和币种；查看完整数值的提示保留该数据的真实月份。部分覆盖、未知和统计期不一致属于必要异常，继续在对应位置提示，不伪装成正常值或零。

月份切换时标题、金额与首充数据一致更新。月份核对将合法的 YYYY-MM 与 YYYY.MM 视为相同月份；缺失或不同月份不得在当前月份标题下展示成已确认成绩。沿用原榜单契约：金额主榜的金额异常不能展示确认名次/奖牌；人数主榜的参考金额异常不取消本身有效的人数排名。顶部本人成绩采用相同校验。

## 验收

实景检查四类榜单、双币种、当前月/历史月切换、规模榜当前月参考、本人栏与普通/冠军行。正常行没有重复月份；表头副标题可读，未挤压原有数字与操作。完整金额提示仍带真实月份。相同月份的两种合法格式通过；不同月份、缺失月份、部分覆盖与未知保留异常，不能误报为正常成绩。现有短名称、简写、绑定客户数、升降、精确值查看、权限入口与原图装饰保持原验收。
