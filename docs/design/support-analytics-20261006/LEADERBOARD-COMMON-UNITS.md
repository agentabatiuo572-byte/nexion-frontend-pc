# 排行榜公共单位

统一单位与统计期放在列标题区：业绩额副标题采用“USDT · 2026.10”等实际币种和月份；首充人数采用“人 · 2026.10”；绑定客户数采用“人 · 截至现在”。规模榜的期间指标仍使用当前月并标“参考”。正常数据行只显示紧凑数值，不重复币种或“人”。

“我的进度”的单位移到摘要标签旁，数值旁不重复。完整精确值、可访问名称和异常依据仍保留真实单位及必要统计期，单独打开时可以明确理解。

表头币种来自明确选中的统计币种，不能从任意一行猜测。缺失或不匹配的行币种不能按表头币种显示成有效金额；金额主榜和本人成绩共用同一校验，不能确认异常金额的名次或荣誉。人数主榜的参考金额异常不取消有效人数排名。异常说明保留原币种/月份与精确原值；既有资金口径、排名和权限不变。

## 本轮短清单

- 复用现有表头、副标签与金额状态校验，删除普通行重复单位，不新增视觉布局或依赖。
- 回归四榜双币、月切换、规模参考、本人栏、普通行与冠军行；表头副标至少13px，窄屏、大数字、精确值弹层、Esc返焦、绑定明细与成绩入口不回退。
- 运行并独立核对缺失查询币种、行缺失币种、错币和仅本人错币；未知不冒零、参考异常不干扰有效人数名次。
- 保留公共日期阶段的历史验收，当前补充按新源码重新运行现有视觉检查并独立审查；更新当前设计预览后实际刷新核对，按当前快照记录结果。

## 字体与数字一致性

动态文字沿用工程字体栈，并对照 3012 即时会话台实际加载的 Manrope 字体；独立预览也加载相同字体资源，不能仅声明字体名称。中文保留工程的系统回退链，不对人数列单独指定另一种字体。已批准的标题艺术字、头像框和荣誉背景继续沿用原稿。

业绩额、首充人数、绑定客户数采用统一的 30px / 600 / 40px 数字样式，冠军、前三名、普通行与四类榜单共用。移除冠军放大、主榜放大、参考金额缩小、伪描边及数字位移规则；榜单重点由表头选中颜色与荣誉标识表达。异常状态采用可读的状态文字，不能借异常样式改变有效数字字号。

验收读取实际数字子元素的字体、字号、字重与行高，并确认 Manrope 字体字节已加载；遍历四榜、双币、全部行以及窄屏和最大紧凑数值，保证同级数字一致、无重叠，精确值展开与键盘返回仍可用。
