# 业绩榜紧凑展示

主人要求名称限制长度，业绩额等统计数字采用 `1000 → 1K` 的简略展示。本契约补充横向采用稿与绑定客户数契约；仅调整展示，不改变存储、统计精度或名次计算。

## 名称

姓名最多使用约8个汉字／16个拉丁字符的展示宽度，同时受实际列宽约束；姓名与组名各保持单行，超出省略，不撑高列表行。完整名称保留在可访问名称、悬浮提示和成绩详情中。姓名后简略升降始终保留可用位置。这里不新增账号命名政策，也不截断已有账号资料。

## 数字

业绩额、首充人数、绑定客户数及顶部本人成绩共用同一简写规则：`K=千`、`M=百万`、`B=十亿`、`T=万亿`，最多一位小数并去掉末尾的零。例如 `1000 → 1K`、`12500 → 12.5K`、`1000000 → 1M`。单位边界四舍五入后升级单位，不出现 `1000K`。

未满1000的人数保留整数；金额最多显示两位小数，非零正数小于0.01显示“<0.01”，不伪装成零。金额单独标明币种，不拼成含义不明的单位。完整精确数字可通过悬浮提示、键盘可达的说明或详情查看。名次、日期、账号标识和百分比不应用金额简写。

格式化不得把精确decimal字符串转换为可能丢失精度的浮点数；优先复用满足要求的现有工具。排序、并列与升降仍以服务端原始精确值为准，两个都显示 `1.2K` 的成绩不自动视为并列。真实零显示 `0`；未知仍显示“待核实”。

## 验收

四类榜单、本人栏、普通行与冠军行使用相同规则。实际核验 `0`、未知、`999`、`1000`、`12500`、单位进位边界、大于安全整数的精确金额，以及小于0.01的金额。核验完整值能通过说明或详情读取，紧凑数字不会参与排序；长姓名不挤掉升降、客户数或操作入口。所有新副标与数值提示遵循可读字体基线，不靠缩小字号容纳数据。

新增绑定列和紧凑显示均为已授权差异。新增币种筛选占位时允许重排顶部筛选与榜单类型区域，保持控件可读；该变更区域单独说明，不冒称与原图逐像素一致。其余装饰仍按采用稿还原，不允许原图人物、旧文字或其他名次泄露。
