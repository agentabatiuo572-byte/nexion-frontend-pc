用户明确要求将归集称为「归集到cregis」、将原付款称为「cregis转平台收款钱包」，并给右侧自动开关加上“自动”。这是对上一轮仅改自动卡范围的明确补充，本轮覆盖 D1 共用资金区的导航、自动卡及人工准备卡；无 App/H5 改动。

当前自动选项为「自动归集到cregis」「自动cregis转平台收款钱包」，人工类型为「归集到cregis准备」「cregis转平台收款钱包准备」。相应标题、状态、地址角色、说明、下拉、记录类型与确认文案一致。历史填写理由按原文显示，记录不改写。

`design.png` 由内置生图工具生成并修正为现有双列准备表单、横排自动选项。提示指定两张深色资金卡、BEP20/ERC20/TRC20、既有绿色选中态、地址占位、关闭状态及完整新名称；下方只保存准备记录，不自动发送。依据 `app/globals.css` V5 双主题 token 与 `app/components/domain-views/d-domain.css` 卡片、表单、分区、按钮、地址与警示规则。

本次只替换文字及对应无障碍名，现有组件、字号、背景、边框和表单布局继续使用代码中的资金域规范；稿件字体比例、状态点及边框细节仅供示意，不新增装饰或控件。图片仅含地址占位，不含真实钱包地址。
