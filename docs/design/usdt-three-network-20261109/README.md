设计依据：`app/globals.css` 的 V5 双主题 token、`app/components/domain-views/d-domain.css` 的资金域卡片、分区导航、表单、地址事实与按钮样式。暗色使用现有深色表面、白/灰文字与柠檬绿选中态；浅色继续由同一套 token 渲染。

生成提示要求：1200×850 PC 紧凑中文资金管理卡，标题后放三网分段选择，展示 ERC20 缺地址及关闭状态、平台与甲方两行地址、禁止启用提示、原双人复核开关、当前网络任务空态；沿用 V5 深色背景 #0A0A0A、卡片 #17171B、文字 #C8CDD6/#8A95A8、选中色 #9EDC1D、10px 圆角和 20px 内边距。底部异常款部分仅作同页位置参考，不增加第二套入口。
