| 问题 | 修复及约束 |

| 行情买卖进入相同兑换方向 | 买入进入 USDT→NEX，卖出进入 NEX→USDT。 |
| PC G7 只能看到首批订单 | 传递服务端游标，按订单号去重追加，失败保留已加载记录，刷新代次压过陈旧分页响应。 |

| 欢迎页把舰队总数当在线设备数 | 在线数按已发布舰队规模×在线率计算，两项有效才展示；不改变其他需要舰队总规模的场景。 |
| App 回到前台仍使用旧平台配置 | onShow 重新读取 PC 发布的平台配置，沿用原有请求合并及失败清空权威数据机制。 |
| 抽奖 CTA 串用固定活动 | 页面传入所选活动 ID；状态、奖池、请求及失败重试键按活动隔离；切活动或关闭后的旧回复不覆盖新界面。 |
| 语言分组标题固定英语 | 分组标题随当前语言变化，补齐中文、英文及越南文。 |
