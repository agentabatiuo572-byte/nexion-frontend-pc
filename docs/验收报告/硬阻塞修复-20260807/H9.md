## 5. 权限、结果未知、并发和回滚风险

### 结果未知与幂等

当前真实链证明两个不同意图各落一次，不等同于已实景模拟“后端成功、响应丢失、同 key 重放”。该路径由 `AdminIdempotencyServiceTest` 18 项和 PC 稳定槽位覆盖；生产前仍建议做一次可控断链重试，确认只新增一条审计/outbox。

### 并发

真实链是顺序 v3→v4→v5，不是两个操作员同版本竞争。CAS/行锁/409 的代码和单测通过，但数据库双会话竞争仍需隔离环境补一次；本 Agent 受禁止 PATCH 约束未执行。

### 回滚与清理

- 本轮业务配置已恢复为 `onlineJitter=24`，注册增长锚保持不变；版本、生效时间、审计、幂等和 outbox 向前保留，不应删除或回写。

- 三仓工作树分别有约 260/222/86 条 dirty 记录，H9 核心文件仍包含未提交项。发布前必须形成可追踪提交、核对 migration 已执行，并在目标提交上重跑本报告门。
