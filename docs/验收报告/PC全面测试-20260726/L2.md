## 技术与墨菲对抗结论

| 检查项 | 结论 |
|---|---|
| 同用户分母与顺序 | 先由注册事件锁定 actor 集，KYC、首购、复投、提现必须是同 actor 且事件时间严格后发生；人数保持非递增 |
| 去重与重放 | 每 actor/阶段取第一条有效事实；重复事件不扩大分子；报表幂等 hash 已加入四个切片字段 |
| 事件时间、迟到与时区 | 留存成熟度固定 `UTC+08:00`，未成熟窗口为 null；迟到 `app.dau` 在下一次查询吸收，不回写历史假值 |
| 空队列/空 cohort | 无匹配切片返回 unavailable，不泄漏或回退到全量 dashboard；初始无完整 cohort 时只展示六项独立事实 |
| A4 与 H2 | L2 查询要求 `analytics_event=1`、`schema_registered=1`、`is_server_authoritative=1`；trial 不再允许客户端权威例外 |
| L1/B3 一致性 | L1 Day7 与 L2 都使用 `auth.register_completed + app.dau`；B3 与 L2 五级使用同一 A4 事件名、同 actor 和顺序连接，L2 不另造来源 |
| E/G/D2 域外真值 | 首购取 `checkout.completed`；复投优先 `wallet.reinvest` 并兼容首购后的第二笔 checkout；提现取 `withdraw.submitted` |
| I/H/F 维度 | Phase、locale、ref 归因固定在注册 cohort；locale 动态发现并包含 `vi`，分组不再 `.limit(4)` 截断 |
| 导出 | 当前切片同时进入 scope、CSV、rowCount、A2 审计和幂等 hash；CSV 含五级漏斗与 cohort 留存，且只含聚合非 PII |
| HTTP 200 脏响应 | PC 校验五级顺序、非负安全整数、人数单调、0～100%、cohort/曲线/动态矩阵与 quality；任一歧义整页失败关闭并禁用导出 |
| 401/403 与角色 | 后端四个读端点均保留 `bi_l2_read`；导出由 `bi_l2_write`/superadmin 控制；匿名真实请求 401 |
