## 对抗性审查

- 并发：同一 `expectedStatus + expectedVersion` 只允许一个不同意图成功；定时关闭也递增版本。
- 幂等/未知结果：M 容器保留稳定 value、reason、baseline 与 `Idempotency-Key`；SSE 抵达不改写重试基线。
- 失败关闭：HTTP 200 结构歧义、空中间页、重复会话、坏消息、缺版本均不生成默认业务事实。
- 权限：沿用 `service_m3_write` / `service_m3_timeout_manage` 与 superadmin 边界，数据不可用时写入口关闭。
- 交接：指定 agent 只能本人接收；queue/standby 由当前可分配坐席接收；退回目标由服务端命令明确裁决。
- 审计：例行交接不进 A2；回复、状态、归档、转工单等审计改为必达，失败不得冒充业务成功。
- 刷新/重登：权威数据来自后端列表+详情，前端运行态不作为恢复真相。
