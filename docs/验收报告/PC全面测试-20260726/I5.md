## 2. 第一性原理与完整调用链

I5 的最小闭环不是“PC 有七章表格”，而是：

```text
PC 新建/编辑草稿
  → 后端法域内单调版本与 01–07 七章校验
  → A2 发布审批
  → 不可变已发布版本历史（此时不改变 App 投放）
  → A2 法域矩阵切换 + 可见快照 CAS
  → 当前 jurisdiction × country × version 唯一映射
  → I6 通知 + disclosure.reack_triggered
  → App current/read token/服务端最短阅读/滚底/勾选/ack
  → G1/G7/D5 等受限动作由服务端确认事实放行或拦截
  → A4 viewed/acked/gated_action_blocked 形成治理证据
  → 刷新、重登、并发与未知结果仍回到同一权威事实
```

按奥卡姆剃刀，版本审批、运行时映射和用户确认是三个独立状态，不允许 PC 文案或 App 本地状态把它们合并。按贝叶斯风险优先审查高概率高损害故障：生产者/回放字段错位、双运营员陈旧覆盖、响应丢失重复提案、原生载体自动放行滚底、确认响应未知。按墨菲定律，所有“理论上不会发生”的缺字段、六章、重复章、无 DOM observer、网络 5xx、超时和陈旧快照都按会发生处理并失败关闭。

## 4. 修复内容

PC：

- 发布确认文案和七章核对卡明确“审批版本”和“切换映射”的不同后果。
- 所有 I5 A2 动作返回并等待提案；同一业务命令按指纹复用 command key，只有结果确定后清理。
- matrix 配置携当前 version/status/countryCodes；归档携 version/status；gate 携当前 scope。
- high-op 命令 schema 与后端 replay 统一使用 `jurisdictionCode`。

后端：

- matrix/catalog 与 gate rows 在事务内 `FOR UPDATE` 串行化；matrix、archive 和 gate 在任何配置、通知、审计前执行快照比较，缺失与冲突均明确失败。
- A2 replay 读取 canonical `jurisdictionCode`，仅为旧票据回退兼容 `jurisdiction`。
- 披露内容必须恰好包含唯一 `01–07` 七章。
- 新增陈旧 matrix/gate/archive 与 canonical matrix replay 定向回归用例。

App：

- current 协议必须有 7 章且章节号精确为 `01,02,03,04,05,06,07`；语言范围只接受后端支持的 `zh+vi`/`zh+vi+en`，双语版不伪造英文，英文界面安全回退中文。
- H5 sentinel 不存在、原生缺 `IntersectionObserver` 时不再自动放行；原生只接受页面 `onReachBottom`。
- ack 响应丢失时读取权威 current，只在同法域、同版本且已确认时恢复成功。
- 新增已提交响应丢失恢复、异版本/未确认拒绝恢复和六章协议失败测试。
