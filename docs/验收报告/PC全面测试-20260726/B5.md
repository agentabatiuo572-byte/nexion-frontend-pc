## 3. 调用链与不变量

```text
B1 coverage
  + D2 withdrawal backlog
  + K1/K2/K4/J3 risk signals
  + J1 five gates
  -> B5 overview + SSE
  -> threshold preview / triage / subscriptions
  -> A2 audit
```

- B5 只聚合、点灯、跳转，不拥有 K4 评分、J1 闸或 D2 状态。
- overview 与 SSE 必须同版本、同五维；SSE 中断要显式陈旧并可恢复。
- 阈值写需 red>yellow、CAS、理由、幂等和 A2。
- J1 缺省闸按 canonical default 解释，但显式非法值必须 503。
- 未知风险码、用户 ID 或状态不能补默认值继续决策。
- 任一来源异常、畸形 200 或 SSE 断线必须失败关闭，不能继续展示旧雷达供运营决策。
