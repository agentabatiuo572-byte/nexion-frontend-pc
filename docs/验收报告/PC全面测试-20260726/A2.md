## 3. 全域调用链

```text
目标域高风险意图
  -> 目标域权限/状态/CAS/B1 前置
  -> A2 提案或单人确认契约
  -> 目标域服务再次鉴权并执行
  -> 同事务业务事实 + required audit
  -> 权威回读/刷新/重登
```

- A2 不能替代目标域权限、CAS、对象版本或 B1 红线。
- 审计失败必须回滚业务；成功、拒绝和失败均须可追溯。
- 同键同意图不得二次回放；同键异 actor/action/target/payload 必须冲突。
- 待执行对象变化后必须失败关闭，不能用旧提案覆盖新事实。
- 全域新增 A4 治理事件时，A2 与 A4 不能出现一边成功一边缺失的半闭环。
