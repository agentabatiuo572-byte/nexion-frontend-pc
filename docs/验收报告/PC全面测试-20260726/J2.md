## 第一性原理闭环

J2 的最小事实不是 PC 名单里出现一个国家，而是“同一可信 IP 国家结论，在所有被声明的真实业务入口之前，由服务端统一裁决；拒绝时没有任何业务副作用；用户能理解原因；控制面写入可追责且可恢复”。

闭环由五个不变量组成：

1. 国家只从可信边缘来源解析，客户端自报头不能改变结论。
2. 黑名单和 endpoint 显式封锁对匹配请求失败关闭；受限名单只允许浏览和风险收缩，不允许新增资金负债。
3. 路由表必须对应当前真实 Controller 路径，不能用历史命名或 URL 关键词推断。
4. PC 写入必须带页面可见旧快照和稳定幂等键；同 key 同载荷重放、异载荷冲突，不同 key 仍由 CAS 决出唯一胜者。
5. 用户端只展示业务可理解的地区限制与“余额未变化”，技术码保留给日志和客服诊断。

奥卡姆剃刀下，本轮没有在每个业务服务再造一套国家判断，而是补全现有显式 `GeoProtectedRouteRegistry`，继续由第一入口过滤器统一执行。贝叶斯更新中，“PC J2 页面曾通过”只能提高控制面可信度，不能证明新上线的 G1/G7/H2/H3/H4/H5 Controller 自动进入路由表；对真实路径逐项比对后，绕过从怀疑升级为 P0。墨菲审查假定路由改名、响应丢失、边缘头缺失、代理伪造、双运营员、旧页面、503、刷新重登和本地语言切换都会发生。

## 权限、幂等、CAS、审计和边缘失败关闭

- PC 按 `emergency_j2_country_manage`、`emergency_j2_write`、`emergency_j2_edge_source_manage`、`emergency_j2_emergency_block` 渲染动作；服务端 Controller 再做权限校验。
- 边缘来源配置只允许超级管理员；财务角色不参与 J2 执行。
- 国家整表、endpoint 和边缘来源写入都携 expected snapshot；无旧快照、陈旧快照、同值与非法转换均拒绝并记录失败审计。
- 同一确认弹窗创建一次 command key；网络结果未知时重新读取权威状态并保留同 key，不直接宣称失败或成功。
- 国家列表批量预检后原子写入；任一非法国家、名单冲突、审计或 outbox 失败时不得出现半表生效。
- 边缘只接受已登记来源的闭集头；可信来源缺头、国家无效或判定源异常均计失败样本并在生产返回 503。
- 旧源只有满足最近 5 分钟至少 20 个可信样本且失败率低于 5% 时才具备 5 分钟回退；未知、过期或不健康旧源不回退。
- J2 成功事件进入持久 outbox，经专用消费者回执后才向超级管理员铃铛展示；前端不把“已写 outbox”冒充“已送达”。

## 统一部署后锁定终验

1. 统一构建并部署同一源码的 8110、3002 和 H5/App；运行 J2 后端聚焦测试及统一 Maven。
2. 从可见登录和侧栏入口重跑本报告全部浏览器场景，不得只测试新增文案。
3. 通过可信代理测试 IP 将可回滚国家加入 limited；逐项调用 stakes、repurchase、trial start/charge、quest/event/points/voucher，必须在业务服务前返回 GEO_LIMITED，钱包、订单、仓位、奖励台账、D4 和 A4 均零新增。
4. 同一 limited IP 调用登录、浏览、event join 和 trial cancel，必须可用；这一步防止过度封锁和未来扣费无法取消。
5. 将同一国家升级 blocked，验证注册、登录和所有请求在边缘拒绝；解除后重新读取并从登录入口完整恢复。
6. 分别注入伪造转发头、可信代理缺国家头、未知国家、候选边缘来源不足 20 样本、旧源过期，验证伪造不可绕过且未知一律失败关闭。
7. 两个运营员从同一旧页面同时提交名单/endpoint/edge source，必须“一成功、一 409”；再做同 key 同/异 payload 重放和响应丢失恢复。
8. 核对成功/拒绝 A2 审计、outbox、消费回执和超级管理员铃铛；清理测试国家、endpoint 配置和临时会话并恢复基线。
