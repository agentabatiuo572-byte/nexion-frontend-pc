## 3. 调用链与不变量

```text
nx_config_item / J1 / J2 / 健康探针
  -> A3 服务器 overview
  -> PC 结构化展示
  -> 超管写 expectedValue + reason + Idempotency-Key
  -> 配置事务 + A2 required audit
  -> Shell 维护公告刷新
```

- A3 不复制 J1/J2 第二写入口。
- 只有服务器登记且存在消费方的键可写；未知键、非法值、同值和旧值冲突全部失败关闭。
- 读取失败必须清除可写依据；结果未知时保留原输入和幂等键。
- 操作者只能取认证上下文，A2 失败必须回滚配置。
- A3 读取与超管写入必须保持精确权限；刷新、退出并重登后仍以服务端当前值为准。
