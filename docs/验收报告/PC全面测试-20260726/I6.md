## 1. 第一性原理与调用链

I6 的业务目标不是“后台能编辑三列文本”，而是让运营发布的同一版本 zh/en/vi 文案，安全、可追溯地成为 App 下一次渲染的权威事实：

```text
PC 可见入口
→ 三语草稿 + 占位符/HTML 校验
→ 页面所见版本 CAS + 数据库行锁
→ 发布/归档/历史回滚
→ 不可变版本快照 + 审计
→ A4 admin.i18n_published/admin.i18n_rolledback
→ 匿名 server-canonical bundle
→ App 启动/前台/切换语言刷新
→ 已验证缓存或打包字典安全回退
→ 刷新、重登、断网和并发仍回到同一服务器事实
```

按奥卡姆剃刀，只保留真实交付的 zh/en/vi，历史回滚复制成新的单调递增发布版，不修改旧快照。按贝叶斯优先验证高损害断点：发布不传播、陈旧覆盖、假语言、原始 HTML、确认提前关闭和归档后不可恢复。按墨菲定律，网络丢失、旧 locale 存储、双运营员、错误 locale、非 canonical bundle、HTML 和无缓存均按必然发生处理并失败关闭。
