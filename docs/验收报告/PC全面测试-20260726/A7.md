## 3. 调用链与不变量

```text
A7 菜单树
  -> A6 角色菜单授权
  -> A1 登录 effectiveMenus
  -> PC 动态侧栏/路由守卫
  -> A8 接口权限仍作最终边界
  -> A2 拒绝/成功审计
```

- 启用子节点前父节点必须有效；存在启用子节点时父节点不可停用。
- 有活跃权限或角色授权的节点不可停用/删除，不得级联破坏 A6 已生效授权。
- 同键并发只允许一条菜单；同键异载荷 409。
- 软删除 code 可复用，但 canonical route 注册表不能被陈旧 metadata 改写。
- 约束拒绝审计不可用时，业务同样失败关闭。
