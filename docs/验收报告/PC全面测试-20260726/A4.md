## 3. 全域调用链

```text
真实业务事务
  -> A4 schema registry 验证
  -> 同事务 nx_event_outbox
  -> durable consumer / receipt
  -> B3/L1-L6/K/B5/运营页面
```

- 资金/状态权威事件必须 `is_server_authoritative=true`；L6 客户端行为事件必须保持 non-authoritative，不能污染资金/KPI。
- 事件名、属性闭集、必填/可选、类型、版本、PII 和 producer/consumer 必须与 live registry 同步。
- schema/outbox 写失败必须回滚业务，不得只返回“业务成功”。
- 相同业务事实重放不得重复投递或重复消费；事件 ID 和业务自然键均要稳定。
- 页面只展示服务器权威注册进度，故障时关闭写入口。
- 读、写、schema 注册权限必须精确分离，前端可见性不能替代后端授权。
