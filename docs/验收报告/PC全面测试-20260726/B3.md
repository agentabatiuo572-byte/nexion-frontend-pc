## 3. 调用链与不变量

```text
App/业务服务器 canonical 事件
  -> A4 registry/outbox
  -> B3 同 actor 严格有序五级漏斗
  -> L2 完整 cohort/留存
  -> H1 Phase 与 L1 KPI 交叉归因
```

- 分子事件必须晚于前一阶段，不可用无序集合抬高转化。
- 只消费登记、允许分析且符合权威边界的事件；trial/行为事件不得污染主漏斗。
- 重复 event_id 和同一业务事实要去重。
- 筛选、趋势、导出和保存视图必须使用同一服务器切片。
- 畸形事实、未成熟窗口或空分母不得显示伪 0%。
- 保存视图/导出的重复意图必须幂等；只读查询本身无 CAS，视图写仍须由服务端拒绝冲突。
