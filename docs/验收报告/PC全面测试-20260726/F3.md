## 技术 / 墨菲对抗审查

### 资金公式与配置

- 匹配公式：`min(A, B) × matchRate`。
- 阈值、比例、暂停、自动安置、结算周期、沉淀策略、归零说明均从事务内锁定的服务端配置读取。
- H1 日封顶从 `GrowthRhythmSnapshot` 读取；页面不再伪造 `$5,000`。
- B1 快照不可靠或低于红线时失败关闭。
- 配置缺失或非法时返回稳定阻断码，不回退前端/服务端假默认。

### 轨道与自动安置

- 只接受 owner 的真实 L1 成员。
- 已分配轨道不可变；冲突返回 409。
- 自动安置启用时，未分配 L1 按成员 ID 稳定排序，优先放入当前人数较少的 A/B 轨。
- 每次自动安置写 A2 审计；安置完成后重新锁定并核对全部 L1。

### 结算、封顶与沉淀

- 每日：任意日可结。
- 每周：仅周日可结。
- 每月：仅自然月最后一日可结。
- 周/月结算按 7 天/自然月天数聚合 H1 日封顶，避免低频结算只得到单日额度。
- 每月清零：只统计当前自然月的有效体量，并扣除当月已经消费的匹配量。
- 转结：统计历史有效体量并扣除历史已消费匹配量，未匹配一侧可带入后续周期。
- 每次对碰清零：结算成功时写入不可变 `from/through volume id` 游标，完整冻结本次 A/B 输入与匹配量；插入 CAS 保证同一 owner/日期只有一个胜者，同一事实重放不再支付，新增订单只进入后续游标窗口。

### 幂等、并发、退款与跨域

- `(ownerUserId, settlementDate)` mutex 加行锁；已存在非 BLOCKED 记录只重放，不重复账本和 outbox。
- BLOCKED 不消耗最终幂等键，修复配置/安置/B1 后可安全重试同一日。
- 已支付订单按订单号捕获；归属歧义、金额冲突或来源不可用时失败关闭。
- 未消费订单退款可作废；已消费订单退款标记 `REVERSAL_REQUIRED` 并阻断新结算，等待 F5 人工冲正。
- 成功结算在同事务产生 F3 记录、F5 cooling commission event、D4 不可变账本、A2 审计和 A4 `commission.paid`。
- 管理员 writer 要求 `network_f3_write`，请求原因 8–200 字；未登录请求应在统一部署后返回 401。

### App 权威投影

- 后端新增登录用户专属 `GET /api/team/binary`，不接受前端传入 owner，避免越权读取他人双轨数据。
- 投影返回真实 Track A/B 分配与体量、自动安置人数、阈值/比例/周期/沉淀/封顶、预计金额、阻断原因和近期真实佣金事件。
- App remote 模式在启动、前台恢复和账号切换时刷新；协议非法、请求失败或账号切换时清空旧快照并失败关闭，不使用本地 mock 补值。
- 双轨页、团队页、佣金累计和钱包累计共同消费同一份服务端事件投影，避免 PC 调参/结算后跨端金额分叉。
