## 3. 跨域调用链与安全边界

```text
A1 登录/MFA/服务端 session
  -> A6 角色真值
  -> A8 权限码真值
  -> A7 effectiveMenus
  -> PC 菜单/路由/按钮
  -> 后端接口再次鉴权
  -> A2 append-only 审计
```

- 权限必须同时经菜单、按钮和服务端接口，前端隐藏不是授权。
- 账号治理为高风险写：理由、认证操作者、稳定幂等键、服务端事务和必达 A2 审计不可缺项。
- 同键同载荷重放不得重复创建或重复审计；同键异载荷必须冲突。
- 角色、状态或 MFA 变更须防陈旧页面覆盖，并在成功后撤销或刷新受影响会话。
- 401/403、Redis/MFA 密钥不可用、注销结果未知和角色差异读取失败均须失败关闭。
