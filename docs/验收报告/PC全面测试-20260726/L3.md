## 1. 锁定范围与单源边界

L3 只做财务分析，不另造资金事实。每项数字必须从对应域的服务器权威来源读取，并在同一周期、币种、精度和业务时区下对账：

| 报表 | 权威来源 | 锁定不变量 |
|---|---|---|
| 收入结构 | D4 总账与订单 / 收益事实 | 恰好四条收入流；金额非负；分项合计等于总收入 |
| 兑付质量 | D2 提现状态机、A4 `withdraw.*` | submitted / confirmed / rejected / delayed / frozen 按事件发生期去重；确认耗时从最早提交事件到确认事件 |
| 覆盖率与净敞口 | B1 储备快照、B2/D6 资产价格、D3 负债 | 储备、负债、覆盖率、净敞口相互可逆；不得把缺失来源补零 |
| 硬负债与到期结构 | D3 九项硬负债、7/30 日到期桶 | 九项分项等于硬负债合计；日期连续；每日分项等于当日总额 |

范围还覆盖日、周、月、季和自定义窗口，上期比较，服务器时区，金额精度，聚合 CSV，脱敏资金明细，A8 权限，L5 审批和 24 小时下载令牌，以及 401/403、空值、大数据、HTTP 200 畸形响应、503、刷新、退出重登、未知结果与重复点击。

## 3. 技术调用链验收

```text
D2 SENT 提现
  -> 服务端链上回执 confirm（状态 CAS、唯一不可变 chainTxHash）
  -> 同事务 A2 必达审计 + A4 withdraw.confirmed
  -> L3 按 A4 event_ts 发生期聚合

B1/B2/D3/D4/D6
  -> L3 七组原始响应
  -> PC 全有或全无严格协议
  -> 四类财务视图 / 聚合 CSV

L3 当前周期 + 九字段
  -> D4 总账创建时脱敏快照
  -> PENDING_CONFIRM
  -> L5 专权审批
  -> READY + 24h token
  -> 仍按报告类型二次授权下载 + A2 审计
```

技术结论：

- D2 新增唯一服务端确认命令，只允许 canonical `SENT` 进入 `CONFIRMED`；链上哈希非空、长度与数据库 128 一致、同提现不可变、跨提现唯一。
- D2 状态、完成时间、A2 必达审计和精确 `withdraw.confirmed` outbox 在同一事务中；任一失败全部回滚。
- L3 兑付的五个计数按 A4 事件 ID和 `event_ts` 去重归期；确认平均耗时使用最早 `withdraw.submitted.event_ts` 到 `withdraw.confirmed.event_ts`，不再使用订单 `created_at`。
- 日、周、月、季分别按自然日历平移上期；自定义窗口按等长天数平移；响应公开服务器 `timeZone`。
- 后端收入缺项、负值以及兑付缺项、负值、非整数均返回 503；PC 在格式化和默认值之前验证七组原始响应。
- PC 严格要求四条收入、A4 兑付源、B1 算术与阈值、九项 D3 负债、连续 7/30 日到期桶及跨源合计；任一歧义整页失败关闭，聚合和明细导出同时关闭。
- 脱敏明细只允许九个财务字段、8～200 字理由、合法日期范围、最长一年和最多 100,000 行；用户编码强制脱敏，CSV 防公式注入，拒绝任何明文 / 解密模式。
- 权限 `bi_l3_export_detail` 在账本计数前检查，无权角色即使数据超限也先返回 403，不泄漏行数。
- 创建成功只进入 `PENDING_CONFIRM`；L5 仅 `bi_l5_task_approve` 可审批，READY 后下载仍需当前操作者具备该报告的精确权限。
- PC 对未知结果保留同一意图的 Idempotency-Key；重复同载荷恢复同结果，同键异载荷由服务端冲突关闭。

## 6. 墨菲定律对抗复审

- D2 不是 SENT、空 / 超长 / 重复链上哈希、并发确认：命令在副作用前失败，CAS 只允许一个赢家。
- A2 或 A4 写失败：确认事务整体回滚，不出现“状态已确认但治理事实缺失”。
- 跨月提交、当月确认：submitted 归提交月、confirmed 归确认月；平均耗时仍按两事件计算。
- 收入少一条、负金额、兑付小数计数、九项负债缺一项、7/30 日期断档、分项合计错误、覆盖率算术矛盾：整页失败关闭，不补伪零，不开放任何导出。
- 合法空数据必须返回明确空集合 / 零事实；来源不可用与真实零严格区分。
- 无明细权限但数据超过十万行：先 403，不通过计数侧信道泄漏规模；有权但超限则创建前拒绝。
- 用户名、姓名、备注、解密字段、未知字段、超一年范围：不得进入创建时快照。
- CSV 以 `= + - @` 开头或带换行：以文本安全编码，不触发表格公式。
- 重复点击与响应丢失：同一意图沿用 Idempotency-Key；不得创建多个敏感快照。
- 非 L5 审批角色、报告 owner 权限已回收、令牌过期：审批或下载失败关闭。
- 刷新、退出、重登后只恢复视图条件，重新读取服务器权威财务事实，不从浏览器缓存恢复业务金额。
