## 3. 联动调用链

```text
A8 权限字典 + A7 菜单树
  -> A6 角色授权
  -> A2 确认/回放
  -> RBAC 关系表 + 缓存失效

```

- 未知、停用、删除或无权限的 permission/menu 必须原子拒绝，旧授权不变。
