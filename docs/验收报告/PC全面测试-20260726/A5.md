## 4. 调用链与不变量

```text
nx_config_item + J1/J2 实时状态
  -> OpsPlatformParamRegistryService
  -> A5 严格 overview
  -> 搜索/域筛选
  -> 真实 owner 页面
```

- A5 只读索引，不创建第二配置源，不允许从名称正则猜 owner。
- 未登记、mock、TBD 或只有前端常量的项不能伪装为已上线参数。
- 任一来源失败、重复键或统计不一致时必须清除旧行，不得保持可点击的陈旧 owner。
- A6/A8 菜单与接口权限必须一致；刷新和重登后重新向服务器取值。
- A5 是纯只读索引，没有写命令，幂等/CAS 不适用；所有变更必须跳到真实 owner 模块执行。

## 5. 统一部署后锁定复验

1. 从同一 BUILD_ID 启动 3002，部署当前 8110，先直查 A5 endpoint 的 200/协议完整性。
2. 从登录页和侧栏进入，核对计数、全部来源、搜索和域筛选。
3. 逐个点击 A3、J1、J2 及其他 owner route，返回后筛选行为可理解。
4. 用无权角色验证 403；注入 503、超时、重复键、计数不一致和单来源失败，确认清旧态并可恢复。
5. 刷新、退出、重登后重复读取；不得出现 5xx、页面崩溃或旧值残留。
6. 由非 owner 重新初审/复审。A5 当前最终分数保持待定。
