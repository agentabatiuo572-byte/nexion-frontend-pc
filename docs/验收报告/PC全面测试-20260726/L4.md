## 1. 锁定范围

L4 是只读运营分析域，不拥有设备、任务、团队或 Phase 的业务真值。四类报表必须分别追溯到：

| 报表 | 权威来源 | 主要不变量 |
|---|---|---|
| 设备运营 | E 域设备台账、A4 `device.* / earnings.credited` | 当前活跃快照与期间购置不可混算；设备和事件重放不可放大 |
| 任务承接 | E 域任务引擎、A4 `quest.* / daily.checkin` | 同用户、同任务，完成必须严格发生在派发后；完成量不得超过派发量 |
| 网络与团队 | F 域关系/佣金、A4 `referral.* / commission.paid / checkout.completed` | 佣金接收人与触发用户分离；比率缺归因时保持 null |
| Phase 节奏效果 | H1 Phase 配置、A4 注册/活跃/商店/结账/切换事件 | P1–P6 单源切片；空阶段不得被趋势桥接 |

验收还覆盖 1 日、7 日、30 日、自定义周期，Phase ALL/P1–P6，保存视图，聚合 CSV，团队树敏感导出，空数据、503、畸形 200、重放、幂等、刷新、重登和权限。

## 3. 技术调用链验收

```text
E 设备/任务 + F 推荐/佣金 + H1 Phase
  -> A4 schema accepted + server-authoritative event
  -> BiReportMapper.selectL4EventFacts
  -> L4OperationsAnalytics（窗口、去重、同 actor/顺序、四报表）
  -> OpsBiService /operations/*
  -> PC 严格协议
  -> L5 聚合 CSV

F 团队关系
  -> L4 敏感团队树导出
  -> 部分隐藏 CSV + 24h token + A2/A4 审计/角色告警
```

复核结论：

- L4 主查询只接受已登记、分析用途、服务器权威事件，不再给 `store.viewed` 客户端例外。
- L1/L4 actor 同时兼容 `user_id/userId/anon_id/anonId`；佣金额兼容 snake/camel；F2 归因独立读取 `source_user_id/sourceUserId`。
- `commission.paid.actor` 是佣金接收人，不能与直推用户直接相交。L1 #7 与 L4 都只用 kind=network 的 `sourceUserId` 匹配 `referral.bound.actor`，佣金必须严格后发生，并按被推荐用户的首笔去重。
- 所有进入计算的事实必须有合法 `event_id/event_ts`；按事件 ID 去重后再做设备、任务和关系的业务键去重。
- 任务接受率只有在 actor 与任务键完整、完成晚于派发时可计算。
- Phase=Pn 只返回该 Phase；ALL 返回有序 P1–P6。某 Phase conversion 为 null 时，下个 Phase 的 step 仍为 null，不跨空洞制造变化率。
- 服务端同时在 service 和 domain 锁定 period/Phase/custom 范围；业务时区固定 `UTC+08:00`，迟到事实只在下次查询纳入。
- PC 要求完整设备/任务/网络字段、非负有限值、安全整数、0–100% 比率、完成≤派发、唯一分组、精确 Phase 行、唯一历史日期、quality/liveFacts 一致；任何歧义整页失败关闭。
- 团队树导出的 day/week/month 改为滚动 24 小时/7 天/30 天，与可见报表一致；custom 仍不开放敏感明细导出。

## 6. 墨菲定律对抗复审

- HTTP 200 少字段、字符串金额、负数、>100%、重复 Phase/历史日期：整页失败关闭，不显示部分零值。
- `available/eventCount/degraded` 自相矛盾或 `serverCanonical=false`：拒绝响应。
- actor 不完整：所有同 actor 比率为 null；network source 不完整：佣金触发率单独为 null。
- 同一事件重复投递：event ID 去重；同一设备、任务、直推关系不会按行数重复累计。
- 完成早于派发、佣金早于关系绑定：不计入分子。
- P1 有 conversion、P2 空、P3 有 conversion：P3 不与 P1 直接做 step。
- period/Phase 未知、坏日期、倒置/未来/超长范围：HTTP 400，不回退到看似成功的数据。
- 503：页面显示可恢复错误；恢复后重新读取服务器真值。
- 团队树重复点击：客户端忙态与服务端幂等双防线；同键同载荷同结果，同键异载荷应冲突。
- 敏感导出：理由、层级、部分隐藏、短期 token、告警和审计必须同时成立；任一未知不得返回可下载成功。
- 刷新/退出/重登：保存的是视图条件，不是业务数据；重新登录后重新读取服务端事实。

## 7. 统一部署后的锁定终验

1. 新 8110 验证非法 period、Phase、非 custom 日期、坏/倒置/未来/超 399 天 custom 全部返回 400；合法 day/week/month/custom 返回精确窗口。

3. 用真实 App 注册、推荐绑定、设备购买/收益、任务派发/完成、F2 network 佣金和 H1 Phase 事件生成干净夹具；核对 A4、L1 #7、L2、L4、F5、D4 的 eventId/sourceUserId/金额一致。
4. 重放同一 event ID，确认金额、次数和历史均不增长，quality 的 `duplicateEventsIgnored` 增加。
5. 在日/周/月边界创建团队关系，确认页面窗口与下载 CSV 行一致；检查部分隐藏、24h token、A2/A4 审计、角色告警、同键重放和同键异载荷冲突。
