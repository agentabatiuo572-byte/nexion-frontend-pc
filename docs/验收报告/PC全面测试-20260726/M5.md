## 4. 修复后调用链

```text
M5 draft + visible expectedStatus
  -> PC 保留同一 command snapshot / Idempotency-Key
  -> backend FOR UPDATE/CAS 校验生命周期
  -> I6 published mirror(key, zh, en, vi, placeholders)
  -> M5 状态更新 + A2 required audit
  -> A4 schema-governed outbox（同事务）
  -> 返回后 PC 重读 overview + 完整分页
  -> M3 只消费 published 内容
```

- I6 缺失、未发布、正文漂移或占位符不一致均在 M5 业务写前返回明确错误，不留下半发布状态。
- 同键同载荷由持久幂等回放原结果；同键异载荷拒绝；不同键的旧页面由 expected value/status 裁决。
- A4 使用认证后的运营员身份；事件 schema/outbox 不可用时事务回滚，不显示虚假成功。
- archived 保持终态；M3 不消费 draft/archived；M4 SLA 与 I6 文案 owner 边界未被 M5 越权修改。

## 6. 墨菲定律复审

- HTTP 200 缺任一字段、重复类别/ID、未知状态、ai 可写、受众不在选项中：整块失败关闭，不把缺失伪装成 0 条。
- 首次请求已提交但响应丢失：只能复用同一 key、value、expected、reason 核对；不得生成第二条内容或第二次状态转换。
- 两个运营员从同一 draft 同时发布：仅一个 CAS 成功；另一个 409 后刷新。
- I6 在 M5 读取后被归档或改版：发布事务按 I6 当前 published 事实检查，缺失/漂移即拒绝。
- I6 中文正文相同但 `{user}` 在英文/越文缺失：拒绝发布，避免运行时插值泄漏。
- A2 或 A4 写入失败：M5 状态/配置回滚；PC 不能先 toast 成功。
- 刷新/重登后：类别、策略、话术、模板和分页全部来自后端；客户端缓存不能复活归档内容。
- 低权限角色即使直调 API：Controller + service 权限仍拒绝；页面隐藏不能作为唯一防线。
