## 3. 验收方法

执行基线：`D:\nexion\页面业务逻辑通顺性验收方法.md`。

本次采用双轨闭环：

1. 首次用户轨：从登录页和可见侧栏进入，不用隐藏 URL；核对页面解释、真实数据、可操作入口、失败恢复、刷新和重新登录。
2. 技术/墨菲轨：检查认证授权、RBAC 精确路由、非法/未知结果失败关闭、幂等键、CAS、双运营员并发、审计/outbox、跨域字段合同、流式下载和数据库约束。
3. 缺陷闭环：发现 → 记录到统一缺陷文档 → 修复 → 定向回归 → 完整锁定范围重跑。
4. 独立复审：模块 owner 之外的子智能体按域组重新审查，避免 owner 自证。
