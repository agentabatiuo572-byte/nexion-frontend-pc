## 权限与失败关闭

- 使用一次性最小权限角色逐个验证 B2/B3/B4/B5：每个角色只拥有自身 `overview_b*_read`，自身菜单/页面/接口为 200，其他接口为 403；同批也验证了 F5 的 `network_f5_read` 边界。
- B2 权限在登录会话中撤销后立即返回 403；恢复权限并重新登录后页面能力重新出现。
- B5 压力分母为 0 时服务端返回 `pressureCalculable=false` 和 `ratio=null`，前端显示不可计算而不是 0%。
- B4 预算缺少四类权威配置时显示不可用，不把负债或资金流水冒充运营预算。
- 畸形 HTTP 200 契约会失败关闭；重试拿到真实契约后恢复显示，不保留伪零。
- B5 对提现正式终态 `REFUNDED` 只识别为已结束、不会误计入积压；未知提现状态和未知告警级别仍整体失败关闭。
- B5 仅拥有分诊权限但没有目标域 read 时，页面不出现跨域处置入口，直调分诊接口为 403；补齐目标域 read 后 5 个入口和 5 条告警链接才出现。

## 阈值与漏斗口径

- `18%` 与 `1.2` 是本次 2026-08-08 产品指令明确指定的当前值，不是从旧 mock 推测。接口返回目标/健康线字段，前端只消费返回值；未来改值必须走版本化产品/配置裁决。
