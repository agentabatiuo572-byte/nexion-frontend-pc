# F 域不合理删除恢复验收报告

## 结论

**PASS。** F5 已恢复六类佣金支出去向、每类总额/笔数、点击过滤和全量状态分布；异常样本、当前页样本和全量聚合严格分开。

## 验收项

- 六类佣金：网络版税（`network`）、双轨匹配（`binary`）、平级奖（`peer`）、培育奖（`cultivation`）、领导奖池（`leadership`）、创世排放（`genesis`），服务端逐类返回分币种金额和笔数。
- 点击任一类型卡会发起精确 `kind` 过滤并刷新流水；再次点击取消过滤。
- 全量状态：冷却中、已解锁可提、已提现、已撤销、已冻结。
- 点击状态项会发起精确 `status` 过滤。
- “已冻结（全量）”来自全表聚合；异常区只显示被阈值命中的样本，不再把样本数冒充全量冻结数。
- 查询不再以最近 200 笔冒充全量；`withdrawn` 状态已纳入分布。
- 缺字段或畸形 HTTP 200 会整体失败关闭，不把缺失金额/笔数补成 0。
- F5 最小角色只拥有 `network_f5_read` 和 F/F5 菜单：自身聚合接口为 200，其他恢复接口为 403；页面六类卡仍可见。
- F1 正式事件 `vrank_reward` 属于 V-Rank 奖励，不是 F5 六类佣金；服务端把它识别为已知域外类型并从 F5 六类总额/总数排除。真正未知类别、状态或币种仍返回错误并失败关闭。
- 类型卡/状态卡显示的“X 笔”与对应过滤接口的全量 `total` 逐值核对；有下一批游标时真实点击并验证事件不重复。
