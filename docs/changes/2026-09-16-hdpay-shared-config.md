# HDPay 代收代付共用配置

按用户 2026-09-16 指令，取消额外的代付独立 enabled、固定 clientIp、D7 provider_ready 和 channelEnabled 配置。代收代付沿用现有商户号、密钥、网关与共享运行模式，代付使用独立回调路径。

D7 取消通道启停按钮，显示只读“HDPay 代付配置：已配置／不可用”。“已配置”是后端配置和本地运行依赖检查，不等于供应商探测成功或到账证明。汇率、费率、限额、编辑权限、CAS、覆盖率与审计保持原契约。旧返回中的 channelEnabled 仅保留兼容投影，旧切换接口返回 410。

App 无需调整请求参数，提交 IP 由服务端从可信请求边界获取并持久保存。后台审核后仍使用原 IP。缺失 IP 的未发送旧单退回审核并保留退款路径；已派发单继续只查询原单。公共隔离测试环境原有仅代收授权不自动扩大为代付授权。

验证：后台生产构建、类型检查、13 项 D7 契约检查；后端 HDPay 签名、回调、幂等、权限、代理 IP 与真实隔离 MySQL 回归。已实际操作本机 3002 D7 页面和 5173 App 银行卡入口。本次未提交真实充值/提现。

现有公网回调地址的代收、代付路径在本机直连与代理检查均连接超时，真实供应商回调与到账不在已通过范围。
