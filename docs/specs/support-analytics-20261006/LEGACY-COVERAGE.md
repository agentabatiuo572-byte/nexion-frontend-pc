## 2. 新布局位置约定

| 位置 | 内容与展开方式 |
|---|---|
| L：左列收件箱 | 顶部标题/总量、超时策略、柠檬色主动联系；搜索及状态筛选；独立滚动会话列表；底部分页。蓝色底与左侧蓝条标识当前会话。 |
| C：中列会话 | 顶部客户及当前客服、会话状态、合法处置入口；中部消息独立滚动；底部常驻模板/商品/图片工具、输入区及柠檬色发送按钮。新增统计不得挤占输入区。 |
| R1：右列身份 | 头像、昵称、业务 UID、等级；完整客户档案入口。内部 ID 在详细资料中独立列示，不替代业务 UID。 |
| R2：右列风险 | 风险等级及客服可读说明，保持直接可见；未知/失败/无权限分别显示。 |
| R3：右列资金摘要 | 保留旧版 2×2：累计成功充值、累计成功提现本金、当前余额、关联工单。币种明确，同一币种视图不混加；多币切换不丢另一个币种。详细资金及流水有明确入口。 |
| R4：右列账户与设备 | 持有设备、算力、IDC托管、地区、脱敏电话、注册/账龄、最近登录；逐行直接展示。未采集不造值。 |
| R5：右列标签与快捷入口 | 保留系统/自定义标签及添加入口；历史会话、关联工单、重置密码、账户操作、添加备注五个图标文字入口全部展开，允许滚动到达，不藏进无提示的“更多”。 |
| R6：新增统计与服务 | 在原右栏内容之后增加“首充与购机”“邀请表现”“活动与维护”；各组保留摘要及展开详情入口。原客服、归属、会话、维护、有效活动及最近服务信息全部保留。 |
| D：完整档案/明细 | 由 R1/R3/R4/R5/R6 精确定位到同一客户、指定分组或记录；可展开长流水、设备、持仓、历史、工单、邀请和活动明细。关闭/返回恢复会话、滚动及草稿。 |

窄屏按“收件箱 → 会话 → 资料”进入并明确返回；保留全部字段和动作，不以空间不足删功能。右栏的折叠仅用于长明细，不能折掉 R1–R5 的摘要与入口。三列具体宽度以配套设计稿为准；旧实际样式的 `440px / 1fr / 296px` 与旧 HTML 的 `312px / 1fr / 284px` 都是不同参考版本，不同时作为硬尺寸。
