# 手机换绑运营配置

依据：主人已批准 APP/H5 手机绑定方案，并于 2026-09-27 指定本仓同步后实施运营后台。PC test 基线 dca2793，服务端 test 基线 771bdfca，均已从远端快进同步。

## 配置契约

- E6 增加是否允许换绑、成功换绑最小间隔天数。间隔为非负整数，0 表示不限制间隔。关闭时仍可编辑间隔。
- 沿用现有 E6 权限、确认理由、A2 审计和幂等保存；读回服务端当前值。开关使用开关权限，间隔使用配置写权限。取消不写入，失败不得伪造成功。
- 服务端字段 E.compute.phoneBinding.allowReplacement（on/off，默认 off）、E.compute.phoneBinding.minReplacementIntervalDays（默认0）；E6 与公共配置增加 phoneBinding 对象，与 APP 已批准契约一致。
- 缺失/非法策略不可展示为已允许。首绑不计换绑；第一次更换从首次绑定时间算，之后从最近成功换机时间算；仅成功更换更新基准。
- H5 手机登记/托管奖励退役，旧 h5BaseFactor 不再可编辑和回放启用；不追回账单，不修改普通注册礼包或已购设备。
- 本轮实现配置闭环；原生安装身份、真实换绑裁决与任务执行仍是独立生产交付项。不得把接口夹具当作实际生产服务联调证明。

## 验收

验证允许/禁止、0天/正整数、负数/小数/非法输入；未授权、缺字段、请求失败、取消和重试。操作后读回并刷新；E6 与 A5 旧入口一致退役。后端验证真实服务方法持久化读回、权限、批量原子性与公共投影。全量工程检查及独立审查记录真实结果，缺少数据库/运行环境如实列未验证。

执行顺序：服务端契约与 PC 配置接线 → 实际组件操作与回读 → 完整回归和独立审查 → commit/push。保留 .claude/settings.json 原有删除。无需额外可点演示。
