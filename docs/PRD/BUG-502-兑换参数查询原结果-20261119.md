# BUG-502 兑换参数查询原结果

## 范围

兑换风险规则的九项直接保存操作适用。包括单用户日额度、平台日额度、手续费率、最低手续费、超额度处置策略、预计处理时长、英文预计说法、中文预计说法和越南语预计说法。四项预计设置的清空同样适用。

## 查询与结案

- 「查询原结果」按原命令号读取原提交人的操作结果。参数行和原操作提醒使用同一查询。
- 查到已保存时结束原记录，重读兑换概览并提示已保存。清空成功时提示已清空。概览读取失败时仍按现有读取失败流程处理。
- 查到明确拒绝时结束原记录，并用现有操作提示说明这次被拒绝。当前查询只提供拒绝结论，具体原因待后端随原结果提供。
- 查不到、仍在处理或结果未知时，原记录继续保留。查询失败时保留记录并提示稍后再查。有权且仍在有效期内的提交人可手动按原操作重试，沿用第一次提交的内容和命令号。过期后只可查询。
- 换账号时仅能看到该账号自己的原记录。无权查询时保留原记录并显示现有权限提示。

本项范围限于兑换参数直接保存。额度和手续费的审批、紧急暂停兑换、取消排队和处理排队沿用各自的原操作查询。
