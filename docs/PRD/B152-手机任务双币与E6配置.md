# B152 手机任务双币与 E6 配置

产品规则见 [uvel-docs 9f2a02fc](https://github.com/agentabatiuo572-byte/uvel-docs/commit/9f2a02fc64c3bf0f10a6abf241d6265fc2238e7c)。

- 手机任务池按秒读取时长。任务每单奖励列按当前 T1–T5 日收益分别预估 USDT 和 UVT，金额按「任务秒数 × 对应日收益 ÷ 86400」四舍五入到六位小数。五档收益未读全时显示 `—`。实际金额由后端派单时锁定。
- 新增、编辑配置名称、类型和 60–86400 秒的时长。新增可选择初始启停，已有任务从列表单独提交启停审批。新命令提交 `durationSeconds`，省略旧固定奖励和奖励资产字段。
- 两人审批继续沿用。调高一档的 USDT 或 UVT 日收益，以及手机池从零个启用任务变为有任务可派时，提示「多付钱」并在批准环节检查兑付覆盖率。审批只影响新派任务。审批中心显示实际修改的任务配置、状态和秒级时长。
- App 沿用当前任务卡、设备卡和算力凭证。任务卡展示锁定的 USDT，设备卡的今日双币按实际入账，凭证按实际币种分行。
