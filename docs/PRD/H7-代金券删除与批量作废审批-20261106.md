# H7 代金券删除与批量作废审批

H7「删除」和「作废未使用」保留原入口。有代金券操作和 A2 提案权限的运营员填写理由后提交审批，页面显示审批单号。待审期间，券模板和已领取的券保持原样。

A2 展示目标券、提案时的券模板版本、可用及已用数量和申请理由。另一位同时具有 A2 审批和代金券操作权限的管理员可处理该单。删除获批后移除券模板，保留已领取的券。批量作废获批后只作废届时仍未使用的券，已使用的券保留。

遇到提交结果未知，H7 保留原理由、原券版本及请求键，刷新同一浏览器会话后可查询原操作。确认未查到审批单且请求键仍在有效期内时，可以按原内容和原请求键重试。超过有效期后仍可查询原审批单。
