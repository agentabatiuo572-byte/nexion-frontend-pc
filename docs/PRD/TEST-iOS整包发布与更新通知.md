# TEST iOS 整包发布与更新通知

运营登记已核验的 TEST IPA、构建号、摘要及签商固定安装地址，在「系统配置 → App 版本管理 → iOS」选择产物，填写三语更新说明并提交。签商安装地址由 TEST 服务端配置，登记前核对已重新签名的 IPA 仍为 `ai.uvel.app.test`，安装链接返回的构建号与登记值一致。

未参与草稿编辑和提交的超级管理员批准后，策略与通知任务一并保存。审批通过即发布，无需再点发布。普通 iOS App Store 整包、Android、资源包及恢复策略沿用现有审批与发布流程。

每个构建号向每个符合条件的账号发送一次。收件设备是获准接收系统通知、绑定当前 TEST 会话且上报低于最新构建号的 iOS TEST 设备。未上报构建号的旧包需要先获得支持通知跳转和版本上报的兼容版本。已升级的设备跳过推送。

点系统通知后进入「版本更新」，查看更新说明并通过原安装链接下载。推荐更新可稍后处理。完成覆盖安装后，版本页显示新版构建号。
