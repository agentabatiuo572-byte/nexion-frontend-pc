# B32-4 G4 首次配置每日收益比例

PC 的「创世节点销售与收益」页面在参数当前为 0% 时，向拥有日分红写权限的操作者显示「首次配置」。进入时读取审批状态，确认配置比例仍为 0% 并取得修订号。发放开关关闭造成的收益汇总 0% 不代表尚未配置。

操作者填写大于 0 且不超过 5% 的目标比例，最多六位小数，并填写 3–128 字的产品或财务决策编号和操作理由。页面用当前修订号提交 A2 审批。待审期间显示原比例，另一位具有日分红写权限及 A2 审批权的超管批准后才生效。提交和批准均由服务端检查兑付覆盖率。

提交结果未知时按原键查询本人审批，可在有效期内使用原比例、决策编号、理由和修订号重试。已确认待审的原审批单可继续查询。已有非零比例的调整、其他参数和分红补发沿用现有入口。
