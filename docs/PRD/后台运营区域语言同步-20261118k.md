# 后台运营区域语言同步

本轮核对后端 `29af0c4a..bd8778e9`。涉及系统配置的运营区域语言和既有活动奖项名的读取。

## `546482ad` 活动奖项名

活动有玩法规则且不是转盘时，列表与详情的 `rewardName` 优先取请求语言下已保存的运营奖项名。该语留空时显示规则计算的摘要。转盘和无规则旧活动继续按请求语言、英文、原奖项名依次读取。奖励明细、资产、金额和发奖规则沿用现行合同。

PC 的管理读取仍使用活动原奖励、各语已存内容和玩法规则。活动卡、App 预览和编辑框的说明待按新事实更新。这里的「修改活动奖励」对规则型非转盘活动修改的是活动原奖励文字。要修改 App 采用的运营奖项名，维护对应语言的「App 上的文字」。

## `6b838c72` 运营区域语言

A3 的体验配置增加 `operatingLanguages`。名单始终包含英文，可加选中文、越南语，按 `en`、`zh`、`vi` 排列。从未保存时后端读取为 `["en"]`。体验配置保存沿用同一个版本与必需审计，省略该项时保留原值。管理端常规读写仍分别要求 `platform_a3_read` 和 `platform_a3_write`。

PC 读取缺少该项的旧配置或旧成功回执时继续使用既有流程。A3 仅把实际修改的名单放入保存正文。版本冲突后，新读到的名单用于未编辑该项的草稿，已编辑的名单随原草稿保留以便核对。恢复按原命令号和已保存的正文重发。成功回执按原提交的版本和语言核对，随后重新读取当前配置。

各内容编辑器可以通过 `getRequiredContentLanguages()` 读取 `GET /api/admin/platform/config/operating-languages`。通过登录且已完成必要账号验证的运营账号可读，返回数据只有运营区域语言。旧接口缺失、读取失败或返回名单不合法时，编辑器的取值回退为英文、简体中文和越南语。

本轮交付读取和保存数据层。A3「发布必填」列、各编辑器的必填标记与提交时的英文补齐作为后续页面接线。现阶段 H4 继续按英文、简体中文和越南语核对开放与首次启用。App 和 Lite 的公共配置消费界面语言 `interfaceLanguages`。

## `6898754d` 活动读取文档

后端文档将列表与详情的 `rewardName` 写为返回数据。App 和 Lite 的活动列表卡片取用这段奖项名，活动列表的领取成功提示也可取用。详情页的奖励区使用该活动的 `rewards` 明细。

## `bd8778e9` 合并核对

PR #54 的合并树与第二父 `6898754d` 一致。8131 实读确认有 A3 读权的账号可在体验配置读到 `["en"]`。无 A3 授权的增长运营账号也可从独立读取入口取得该值。公开平台配置仍提供 `interfaceLanguages`。写入、原键回放和奖项名分支按源码核对。
