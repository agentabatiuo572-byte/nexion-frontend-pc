# D1 / D5：USDT 分网络资金控制

按用户 2026-11-07 确认的图中方案及 2026-11-08 确认的 TRC20 增量范围实施。构建、TEST 发布、页面操作与真实链上资金验收分别记录。

## D1：充值与地址设置

「收款与出款开关」为 BEP20、ERC20、TRC20 各显示一行充值开关、实际状态、未生效原因及独立提交审批按钮。开关开启且库存不足显示「地址准备中」，不把库存不足显示成网络关闭。读取不到新契约时明确提示无法编辑，不伪造默认值。兼容旧两网响应；缺少 TRC20 时该行显示尚未配置、实际状态待核实，不允许提交、补池或对账。

分网络充值开关、待复核与紧急停用区域的字体沿用 D1 相邻充值设置层级：区块标题 14px/600，正文、表头、当前配置、实际状态、目标标签及跳转链接 12px，网络名称与总闸小标题 13px/600，小按钮沿用 11.5px。字号修正不改变开关值、审批、权限或业务文案。

每行提交只改变该网充值，必须由另一名仍有权限的管理员复核。共享闸版本和网络版本变化后旧提案不可通过。草稿随本行版本更新，其他行刷新不覆盖尚未提交的本行选择。

本人发起的申请禁用「复核通过」「拒绝」，并就地显示「这是你发起的，需要另一位管理员处理」。提案、复核、紧急停用发生结果未知时，在「充值与地址设置」保留当前管理员的原请求恢复入口；原路径、参数、理由和请求号保持不变，恢复前不另建同类提案或同一申请的复核请求。未知提案不阻断紧急停用。恢复取得明确结果后重读实际状态；读取失败明确提示，不能当作状态已核实。建址、补池、对账等其他写操作不纳入此恢复入口。

实际开放 = 网络运营开关 + 服务启动/RPC 配置 + 全局分配地址及入账总闸。普通单网关闭不关闭其他网络。恢复共享充值闸须明确提交恢复审批，其他网络充值保持关闭，不恢复出款。

全局出款总闸作为 BEP20、ERC20、TRC20 三网共同上限单独显示和审批；分网络出款跳转 D5，D1 不增加第二套分网出款开关。紧急关闭关闭全部共享资金闸及三网充值权限，按钮与确认说明同步写明三网，后续分别审批恢复。只读人员可查看状态，不能提交或审批。

资金状态、出款能力和地址池网络选择加入 TRC20（TRON）；三网独立显示库存和对账结果。共同充值规则仍共享最低额、固定费和确认数（15–10000），已发现交易保留原规则；TRC20 还须满足固化区块核验。地址池共用补充目标，但 TRON 库存、地址及交易标识不与 EVM 混用。银行充值入口和对账渠道说明同步标明三网。

订单付款与手续费加入 `CREGIS_USDT_TRC20`，网络为 `TRC20`。复用现有网络选择、费率表、付款记录、详情和原请求恢复。未返回该渠道的旧响应可读取，TRC20 费率页显示尚未配置且不可编辑，不补写默认费用；显式返回但尚未配置费用的渠道继续沿用既有填写流程。TRON 详情说明外部钱包可能另收 TRX 或消耗能量、带宽，不误标 BNB；不把付款成功直接视为业务履约完成。

「自动归集与甲方付款」「归集与甲方付款准备」明确标注仅 BEP20。本轮不扩展 TRON 自动归集、甲方钱包配置或付款执行。

## D5：提现参数配置

保留 TRC20 / BEP20 / ERC20 独立控制与既有审批流程。每网沿用本页其他设置的参数行、字号、间距、虚线分隔和小按钮，不另设状态卡片。当前配置以「已开启 / 已关闭」文字显示；操作按钮单独写「关闭通道 / 申请开启」，点击先进入原确认或审批流程，不能把按钮文字当作当前状态。移除「三个一起保存」文案：每次只调整所选网络，其余网络配置保持原值。

配置值和「实际可用」分开显示：每网呈现当前配置、实际状态、不生效原因，并提供 D1 USDT 资金设置入口。配置已开启仍可能实际不可用，按后端原因提示；缺少该网权威状态时显示「尚未核实」，不推断可用。顶部网络摘要只列后端 `effectiveNetworks`；无实际可用网络明确显示暂无可用网络，旧接口未提供权威状态时显示尚未核实。

页面实际网络与 App `/api/withdrawals/policy` 同源：D5 开关、全局出款总闸、服务商币种、RPC、风控与对账均满足才可用。TRC20 也必须满足项目实际收付权限及独立 TRON 节点要求，配置缺失或未启用仍按真实原因显示不可用。页面不把「D5 配置开启」宣称为 App 已可提现。

TEST 自动完整对账周期为 5 分钟（`NEXION_CREGIS_FULL_RECONCILE_MS=300000`，上一轮结束后计时）；每轮核验到约 5 分钟前。最近成功与对账进度的 15 分钟安全门槛、成功后新失败的暂停条件均保持不变，避免原 15 分钟周期造成的约 5 分钟固定空档。真实对账或其他安全条件不满足时仍按实际原因显示不可用。此项是运行参数修正，不改 D5 页面、网络运营开关或审批流程。

## D5：加强合规审查与大额审查窗口（2026-11-08）

按本轮确认的关闭/开启效果图及 TRC20 增量，右侧「随运营阶段变化的设置」依次显示当前运营阶段、加强合规审查、分网络审查窗口、当前执行规则。复用现有参数行、虚线和间距，标题 13.5px、说明 12px、值 15px；保留 H1 读取权限控制的只读跳转，不增加开关或修改入口。左侧业务配置、审批与版本流程保持原样。

本轮另经确认同步两处旧说明：顶部小额免审卡改为「低风险且未开启加强审查时，可自动审核」；左侧绿色提示改为「新提现按小额免审线和风控结果审核；开启加强审查后须人工复核。到账截止时间按配置计算，链上确认后才显示到账。」仅修改这两处文字，字号、布局、参数和按钮保持原样。

以下大额窗口条件仅适用于 BEP20/ERC20；加强审查开启后的人工复核要求仍适用于全部新 USDT 提现。

| 当前加强审查 | 新 USDT 提现的审核方式 | BEP20/ERC20 大额窗口 |
|---|---|---|
| 关闭 | 沿用小额免审及现有 K3/K4 风控 | 不附加 H1 等待，即使配置 N 大于 0 |
| 开启，金额 ≤ 服务端门槛 | 全部须人工复核，小额免审暂停适用 | 不附加 N 天 |
| 开启，金额 > 服务端门槛 | 全部须人工复核 | 附加服务端 N 天；N=0 不额外等待，仍须人工复核 |

TRC20 每笔提现按原提交时间加 H1 的 N 天计算阶段窗口，不受加强审查开关或 1,000 USDT 门槛限制；N=0 无额外阶段等待。小额免审只免人工，不免 TRC20 阶段等待；是否人工、延迟、冻结仍按加强审查及原风控规则处理。窗口到期不自动解除其他风控，不等于批准、出款或到账。

门槛来自 D5 `GET /api/admin/withdraw/limits` 的只读 `complianceReviewThresholdUsdt:number`（本轮服务端为 1,000 USDT），`sourceByField.complianceReviewThresholdUsdt='compliance-rule'`；`complianceHoldEnabled`、`cooldownDays` 继续来自 H1。PUT 回读相同契约。界面不写死 1,000 或效果图用于演示的 7 天，窗口天数始终呈现服务器实际值。N>0 显示 TRC20 每笔适用；N=0 显示无额外阶段等待。

开启时「当前执行规则」明确全部人工、仅严格超过门槛的大额附加 N 天，并说明到期后仍须复核放行，链上确认后才显示到账。关闭合规不能解除已有风控冻结/延迟，也不能修改历史费用；BEP20/ERC20 使用同一合规规则，网络可用性仍分别核验。

旧接口同时未提供门槛和来源时，BEP20/ERC20 大额条件及执行规则显示待核实并提示刷新或到 H1 查看；H1 已提供的 N 天及 TRC20 阶段说明仍按权威值显示。不默认门槛或声称缺失的规则已核实。只缺一项、来源不符、非正数或非法值时沿用 D5 加载失败、清空旧值与重试。接口失败及版本冲突仍使用既有恢复路径。

验收实际打开 D5 并刷新，核对关闭、开启 N>0、开启 N=0、旧接口缺字段及异常恢复；检查权限受限者没有新增写入口，跳转仍受 `growth_h1_read` 控制。页面操作和独立设计评分另存验收证据，不以构建通过代替实景验收。

## D2：TRC20 供应商原单核对（2026-11-08）

三网沿用 Cregis 提现详情和原 CID 核对恢复。只有服务端明确允许恢复且本单 `source=provider` 时显示核对入口；核对只绑定、查询原单，不新建出款。供应商已接手的本单不提供通用放行、退款或重新发送操作；尚未取得本单供应商事实的处理中、已发送或异常订单也不显示通用退款动作。权限、原请求幂等键和未知结果恢复流程沿用既有实现，后端仍是最终执行边界。ERC20 丢失链上确认的原冻结及占额规则保持不变。

## App / H5 Lite 与业务影响

充值先读只读 `GET /api/deposits/policy`，不通过请求各网地址探测开关；只显示开放网，并从 policy 读取准确费用。选中后才申请地址，全部关闭或读取失败不默认申请 BEP20。库存不足仍允许显示该网的准备中状态。

提现及地址换绑只使用实际开放的提现网络；全部关闭时不能换绑或发送验证码。服务端申请、保存换绑、首次出款分别复核权限，成功幂等回放和已发出原单查询继续可用。外部 USDT 下单及付款履约受选定网充值开关控制，余额购买沿用原流程。

## 验收

实际操作 D1 三网独立提案和双人审批、地址池切换、付款费率与原单详情、D2 TRC20 原 CID 核对入口、D5 开关及分网络窗口说明、App / H5 Lite 初次充值加载及地址换绑。验证关闭网络不能通过旧页面或直接写接口继续操作；检查只读 policy 不消耗地址。兼容旧两网响应时 TRC20 未配置且不可操作。页面按已确认范围与现行 D 域规则完成独立复核。构建、类型检查不能替代实景；未执行的真实链上资金动作不得宣称通过。
