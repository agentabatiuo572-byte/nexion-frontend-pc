# H3、H4、H5 退役入口与检查间隔

- H3 可查看历史月度挑战、状态和原任务路由。新任务配置不提供质押、创世认购和月度挑战新建，创世转让市场保留。
- H4 转盘新增和编辑可选 UVT、USDT、代金券。历史积分档保留原奖项和概率，不能编辑、删除或改概率。概率合计在退役前仍包括历史档。2026-11-12 后端新增积分档专用退役，PC 已准备请求及原号恢复服务，明确入口和提示待视觉 worker 接入；退役后须由运营用合法 UVT、USDT、代金券奖项补足有效奖池至 100%，不自动替换或补概率。
- H5 目标业务已停用的连签权益保留原配置和说明，显示只读。检查间隔由拥有专用授权的超级管理员修改。


## 2026-11-16 相同配置与读取状态

H3 普通文字配置和任务译名、H5 单值与多字段配置沿用共享表单现有的 `disallowCurrent`／`requireAnyChange`。原值、冲突重读后的最新值与输入一致时不能再保存，不额外生成审计或提案。原请求恢复仍按保存的完整原请求处理，不套用新修改的同值校验。H8 同额保存还会重设奖励政策生效时间，未将这一限制扩展到 H8，需单独决定。

H4 玩法规则的恢复读取按 `ruleError` 更新读取可用状态；只有读取成功才将旧行作为当前数据。保存动作不解除读取失败。停用玩法允许保存未完成配置，启用仍由后端校验完整性；本次不决定空表单应存 `{}` 还是含空值的草稿对象。
