# B31 PC 菜单名称与顺序

PC 侧栏把「平台基础 A」放在「客服中心 M」之后。页面搜索和面包屑使用同一组页面名称。A6 的角色菜单树和 A7 的菜单树读取已更新的中文名称。各角色现有落地页按当前授权解析。

| 菜单码 | 中文名称 |
|---|---|
| A5 | 平台参数目录 |
| B3 | 用户转化概览 |
| D1 | 充值与收款对账 |
| D2 | 提现审核 |
| D5 | USDT 提现参数 |
| D7 | 越南盾提现参数 |
| E6 | 手机算力配置 |
| G2 | 兑换额度与规则 |
| G3 | UVT价格管理 |
| H5 | 签到与UVT奖励 |
| H9 | 首页与网络展示设置 |
| I5 | 法律条款与风险披露 |
| I6 | 多语言与课程 |
| L4 | 设备、任务与团队报表 |

已有环境通过前向迁移统一这些中文名，包含旧 I5 节点。迁移覆盖指定节点现存的自定义中文名。菜单码、路由和授权保持原值。
