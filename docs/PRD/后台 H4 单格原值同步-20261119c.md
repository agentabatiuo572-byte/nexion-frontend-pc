# 后台活动文案与原命令同步

## I6 完整性修复 · `9081d087`

修复请求可携带扩展语 `translations`。省略时沿用已存译文，空对象表示清除扩展语，传入对象则按实际内容保存。现有三语编辑入口省略此项。重扫也检查已填写的扩展语中的占位文本和退役品牌。修复保存新草稿及对应版本，报告仍按实际公开文案或未发布词条的最新版本计算。

修复回执沿用问题类别，并可带实际保存的 `messageKey` 和 `version`。后台核对原问题类别、原词条及版本。看到两个新增字段时，新版本须晚于能够从原操作记录读到的版本。修复分配版本时已有草稿可能更晚，回执可比画面上的旧版本多一版以上。旧回执缺省这两个字段时沿用原问题类别校验。按原请求重试使用原正文和命令号。通用只读回执仍只提供业务状态，无法给出实际修复数或保存的草稿版本。
