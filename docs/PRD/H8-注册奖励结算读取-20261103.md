# H8 注册奖励结算记录

运营在「增长与活动」的「新人礼与邀请奖励」查看最近结算。每条记录的新人编号 `invitedUserId` 必须为正整数，邀请人编号 `inviterUserId` 可为空。

使用好友码注册的记录显示实际邀请人编号和邀请奖励。无码或使用客服邀请码注册时，H8 读取该新人的礼包结算，邀请人一栏使用已有空值占位「—」，邀请奖励为零。有效的新人礼包和同一页的其他结算记录继续显示。数据来自 `GET /api/admin/growth/referral-rewards`。

加载更早记录失败时，在列表旁说明加载失败、当前列表尚未完整，保留已加载记录和原游标。点击「重试加载更早记录」重新加载同一后页；成功后追加记录并推进游标，失败不显示为空结果（BUG-260）。
