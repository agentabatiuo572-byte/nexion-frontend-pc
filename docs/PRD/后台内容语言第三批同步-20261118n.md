# 后台内容语言第三批同步 · 2026-11-18

后端合同以 `1589b4a5` 为准。本批来自 PR #57 和 PR #58，含期间合入的词条已发布版本、信任版块证据与宽度、历史数据保护和活动奖励读取。新建与保存要求英文及已选运营区域语言，未选的中越整组空白时保存对应英文，部分填写仍须完成同组。各编辑器的必填项、打开副本的留白和提交前补齐由共用语言规则统一接入。

## 改版线的请求与回执

| 入口 | 发送和接收 |
|---|---|
| I1 文案对比测试 | 新建、存草稿及发布继续发送三份正文、位置、版本和适用条件。保存及发布以当前文案修订号为前提。发布已存原稿或尚无目标稿的新版本时修订加一。发布对已有草稿的修改在同一次命令下先写草稿再发布，回执修订加二。兼容原号回放和旧服务的加一回执。回执以文案键、目标版本、发布状态和允许的修订号为准。成功后重新读取，原号查询和重试仍使用首次请求的对象、内容和命令号。 |
| I6 多语言 | 概览的 `messages` 仍是各键最新版本，`publishedMessages` 提供独立的已发布版本映射。缺省表示旧读模型没有提供该映射。词条编辑、修复、发布继续携带三语或已存稿的三语值。发布比较已存内容，词条修订、发布和历史回滚的版本回执口径沿用原合同。扫描按运营区域语言判断缺语，覆盖率的后台统计仍按已发布且三语齐全。会话话术和快捷回复的新稿以英文为原文，保存沿用词条语言规则。 |
| I7 课程与测验（在 I6） | 新课、课程草稿和版本草稿仍提交三语标题、正文和逐题选项。写入的同语分组跨整门课。正确答案下标和选项次序与请求一致。补齐后中文主标题最多 128 个码点，超长拒绝。纯空白扩展语题干或整组选项从规范内容移除，已填写的选项需逐项完整。草稿回执仍按目标标识、状态、版本和适用的修订号核实。课程激活及回滚使用已存版本，主标题宽度也在激活与回滚时检查。 |
| I4 信任中心 | 草稿仍发送键名、标签和值，以及原版块和草稿快照。回执验证请求顺序和原有字段。空白选填语可回同字段族的英文值，缺失的语言键可由既有模板或英文键派生后附加。扩展译文仍可随已存稿保留。受支持的旧共享文本字段可升级为本地化族，保存后可据真实字段重新编辑。英文齐全的历史公开内容允许缺中越字段，缺语按既有客户端规则处理。审批依据已存版本、结构和原修订。 |
| I5 风险披露 | 总文及七章标题、正文按语言整组保存。保存正文的 `en` 范围别名落为 `zh+vi+en`，现有扩展范围可保留。发布请求指向准确版本、修订和哈希。提案预检、发布执行及地区矩阵激活校验已存范围含英文，并具备英文总文和七章英文标题、正文。拒绝为 `422 DISCLOSURE_EN_REQUIRED_FOR_SCOPE`，后台通过现有中文错误说明呈现。法律条款和隐私政策各走独立合同。 |
