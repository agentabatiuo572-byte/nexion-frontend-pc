# BE-19 · B0 漏斗、B3 用户转化与 L2 留存

B0 漏斗卡和 B3 转化概览对后端标记的小样本显示「样本过小」，清空对应数字、比例和图形。B3 保留日期和渠道标签，渠道图含被隐藏项时按原百分比列出可见组。没有注册数据时继续展示原有空状态。

L2 漏斗、阶段展开、试用路径、周月留存、曲线与多维交叉按对应行或单元格的保护标记展示「样本过小」。已保护的留存组不画曲线，也不作为曲线对比组。注册人数至少 5 人的成熟留存窗正常显示，未成熟窗口保持空值。导出仍走既有确认与权限流程，新生成的文件使用同一保护口径。

已生成的 L5 文件仍可按原权限下载。产品保护按单次请求内分组执行，跨筛选的汇总差分推算不在本期范围。
