# F1 条件与奖励模板审批（2026-11-05，BUG-286）

适用 PC F1 的自购算力点、团队算力点、直接邀请人数、达标分支数、分支最低等级，以及既有奖励模板新增、编辑与移除。沿用已确认局部设计和现行深浅主题、键盘确认外壳，不调整其他 F 页面。首次 V0–V8 整套初始化继续使用原审批合同。

| 维护方向 | 生效方式 | 确认与结果 |
| --- | --- | --- |
| 有效晋升条件放宽 | A2 双人审批，与本级是否已有资金奖励无关 | 具体条件、当前值、拟调整值、必填理由与“提交审批”；另一位有审批权的超管批准前仍按旧条件评估 |
| 收紧或没有实际放宽的条件修改 | 原 PATCH 即时维护 | 必填理由，后续评估使用新值；存量等级及历史晋升保留 |
| 新增 USDT/UVT、同币种提高、非资金改资金 | A2 双人审批 | 当前与拟奖励对比；待审不创建可发放模板，批准后后续发放使用新值 |
| USDT↔UVT | 提案、批准分别按 B1 当时 UVT/USDT 价格精确估值；增加才审批与覆盖率检查 | 使用服务端奖励 amountText 及 rewardValuationUsdtPerUvt；不经 Number 舍入。价格不可用时只阻止跨币种切换，不阻止同币种收紧 |
| 降低、等值、资金改非资金、非资金编辑 | 原维护接口即时生效 | 不因 B1 低覆盖阻止收紧，已发奖励类型及金额快照保留 |
| 移除模板 | 原 DELETE 即时维护 | 停止之后的发放，历史奖励与账本保留 |

分支方向与实际晋升引擎一致：分支数为 0 时改分支等级不算放宽；分支数大于 0 且等级未设置时降低正分支数仍不满足有效条件，不算放宽；此时设置有效等级算放宽。有效分支条件降至 0 算放宽。有效分支数或最低等级降低算放宽。输入只允许本级以下的有效等级或未设置。

审批命令为 `{domain:'F',op:'f1_rank_policy_change',params:{values:{rank,expectedRevision,action,field?,value?,rewardId?,reward?}}}`，action 为 threshold、reward_add 或 reward_update。目标锁 `{domain:'F',type:'vrank_policy',id:rank}`。所有资金金额以小数字符串提交，最多 12 位整数和 6 位小数。审批绑定本级条件及奖励 revision，期间发生其他维护时旧提案不能覆盖新配置。服务端重建审批前后值，提案和批准均检查 B1 原始精确覆盖金额；只配置模板，不预造未来晋升人数或即时资金支出。

发起与本人原键查询要求 network_f1_write，不额外要求 A2 read；批准要求超管、platform_a2_operation_approve 且与 Maker 为不同账号。权限与单人禁止由服务端最终裁决。

原操作按账号、等级、动作（条件字段或奖励编号）隔离。发出请求前持久保存原表单、前值快照、理由、版本、操作者、完整请求及幂等键。丢响应、关闭重开或刷新均显示并锁定原值和理由；审批先查询本人原键，确未找到时仅允许原命令原样重试。查询失败、过期或对象不符时保留证据，不生成新号。直接维护未知结果也只允许原请求同键重试。只有取得确定回执及当前配置后收敛原记录；成功提示不将待审误报生效。

用户于本轮明确确认 [F1 原移除恢复入口设计参考](D:/workspace/artifacts/tabor-bug286-f1-20261105/F1-原移除恢复入口-设计参考.png) 的局部增量：仅在该等级奖励区域存在本人尚未确认的移除命令时显示“移除奖励结果待核对 · 核对原操作”，其他等级、账号、动作和没有待核对命令时均不显示。即使后端移除已经成功、响应丢失且刷新后原奖励 chip 消失，也可从该局部入口重开原移除确认框；原奖励、理由和请求编号取持久原命令并锁定，只允许原请求、原幂等键重试，不恢复已删除奖励，不创建审批，不增加权限。

局部入口同时绑定原命令号。原命令已经收敛或入口失效时不重新创建移除命令；恢复成功并回读当前配置后入口消失。换账号不展示或恢复其他人的记录，沿用既有会话归属和权限判定。过期记录保留待核对证据但不得重发。全页顶部通用恢复入口仍未应用。

验收计划通过真实 PC 操作条件、五种奖励、同币种及跨币种方向、收紧/移除、另一超管 A2 批准和回读，覆盖深浅主题、键盘、无额外 A2 read 的 Maker、丢响应与重开恢复。局部移除恢复另验后端已移除加丢回执、刷新后只在原等级出现、换账号隔离、原值/理由/命令号锁定及重复恢复不新建命令、不恢复奖励。类型检查和 production build 只证明候选可构建；页面与完整业务验收由本轮主任务记录。

2026-11-05 隔离实景已验证无资金奖励 V8 放宽、另一超管批准后回读及即时收紧；资金奖励最小精度上调、跨币种等值直接维护与增值审批；HTTP 200 后丢回执、刷新找回原审批单，以及原奖励 chip 消失后的本级移除恢复。移除重试的 URL、理由、请求体及幂等键均与原请求一致，成功回执及移除审计各一份。其余四项条件已核页面前后值和审批方向，实际服务写入/批准的覆盖范围引用后端专项业务证据，不等同于四项全部重新走完 PC 提交。深色视觉独审 9.1、9.2，平均 9.15。
