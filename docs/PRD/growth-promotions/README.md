确定需求：促销/裂变分类；新客、无设备、老客和等级可配；设备/USDT/NEX三类奖励；活动时间；买A赠B、买D赠C、同单多设备各自赠礼；嵌入现有购机流程；首页仅在原轮播增加广告、保留快捷入口；活动奖励接入既有奖励记录第四类别；真实期限挽留。APP/H5沿现有APP元素实施，每完成一页截图并验证功能和状态，至少两名独立agent审查功能、UX与一致性；PC保留既有像素审查，未达要求持续修改复验。

主文D01–D11只记录需要业务决定的政策，不把建议当成已批准默认值。本文档包在活动中心所属PC仓维护；APP/H5与服务端接入同一版本，避免复制出多份金额和发奖规则。
