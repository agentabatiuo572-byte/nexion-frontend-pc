# B53 商品系列与选品

2026-11-19 产品确认。E1 创建商品时逐个指定系列。SKU 编号用于唯一定位商品，符合现有编号格式即可。

## 商品和设备系列

- 商品系列有 Cloud Share、S1、Pro、Pro v2、Rack P1、Rack P2。同系列可配置多个 SKU，每款商品使用自己的价格、库存、收益和任务配置。
- E1 基本信息必选所属系列，编辑和商品详情回显系列，A2 审批显示前后值。商品一旦有订单或发出过设备，系列即锁定，后端在提案和执行时检查。其他字段按现有权限维护。
- 设备交付记录保存系列。迁移回填可确认的旧商品和设备，无法确认的记录在上线前核对，禁止按名称或编号实时猜测。
- 产能下降、月收益目标资格、任务路由、App 设备分类和首页推荐使用明确的系列。Cloud Share 同系列新 SKU 按其设备购买时快照发每日 UVT，沿用当前订单、激活和同 UTC 日去重规则。B52 硬件每日 UVT 按 E3 产能折算。

## 指定商品

- H2 试用商品复用既有选品。候选为允许试用的在售实物 SKU，并满足库存等现有条件。新领取读取当前配置，进行中试用照原 SKU 展示和结算。
- E6 的 S1、Pro、Rack 三个对比行分别选对应的在售实物 SKU，要求收益配置完整。操作者核对目标商品并走 A2 审批。手机行读取 T3。商品不可用时，PC 提示重选，App 隐藏该行并继续手机校准。
- App 首页和设备相关页面按后端分类，商品名称、图片、跳转和订单仍使用具体 SKU。现有 App 新手引导的两张商品对比卡使用配置对应商品。商城收益阶梯沿用当前代表商品。
