# B53 商品系列与选品

2026-11-19 确认方案。后端规则见下；PC 已按「PC 行为」交付，尚待两个真实管理员账号在 TEST 验收；App 另行交付。

## 后端规则

- E1 创建商品时必须为每个 SKU 指定系列。系列包括 Cloud Share、S1、Pro、Pro v2、Rack P1、Rack P2。同系列可配置多款商品，每款商品独立设置价格、库存、收益和任务。SKU 编号用于定位商品。
- 商品一旦有订单或发出过设备，系列即锁定。后端在提案和执行时检查，其他字段按现有权限维护。
- 设备交付时保存系列。迁移为能确认的旧商品和设备补齐系列，无法确认的记录在上线前核对（后端 B53-BE-07 已确认生产没有这类数据）。产能下降、月收益目标资格、任务路由和设备分类读取明确的系列。
- Cloud Share 新 SKU 按设备购买时的快照发每日 UVT，沿用订单、激活和同 UTC 日去重规则。B52 硬件每日 UVT 按 E3 产能折算。
- H2 试用候选为允许试用的在售实物 SKU，仍须满足库存等现有条件。新领取使用当前配置，进行中的试用使用原 SKU 展示和结算。
- E6 三个商品对比行分别保存所选在售实物 SKU，并读取商品名称和收益。换绑走 A2。手机行读取 T3。商品不可用时，公共接口跳过该商品行并继续返回手机配置。

## PC 行为（2026-11-20）

- **E1 所属系列。** 新增和编辑商品的「基本信息」里有必选的「所属系列」：新建按档位给选项，编辑按商品原来的类型给选项；共享份额只有 Cloud Share，实物商品不能选 Cloud Share。商品编号只做唯一标识，不再要求含型号标识，旧的编号提示已去掉。
- **校验。** 没选系列、系列和商品类型不符、锁定后改系列，提交前就在「所属系列」控件下报错并定位到「基本信息」；审批返回的系列错误也写回这个控件。
- **锁定。** 有订单或已发出设备的商品，「所属系列」显示为只读值，旁边的提示图标说明为什么不能改；其他资料照常可改。已锁定却没有系列的商品不能保存，系列在这里补不了。
- **被别人改过。** 编辑期间商品被别人改过时，不能直接再提交，关掉确认框重开也一样；核对并采用最新内容后，本地没改的项用最新值，改过的项保留输入，再按最新修订提交。
- **列表和详情。** 商品卡在编号、档位后面写「S1 系列」这类名字；没有系列的存量商品写注意色「未设系列」，卡片原因写「未设所属系列，编辑时先选系列」，目录结论可一键筛出「未设系列」的商品。商品资料抽屉首行和「基本信息」都有「所属系列」，锁定时带「已锁定」和提示图标。不按编号或名称推导系列。
- **确认和审批。** E1 确认框的完整差异、提交到审批的前后摘要、「操作记录与审批」的「完整变更」都写「所属系列」和名称（Cloud Share、S1、Pro、Pro v2、Rack P1、Rack P2），不出现代码值；新建没有前值，旧审批单没有这一项时不补。
- **E6 新用户引导收益对比。** 表格列为对比位、当前商品、USDT/天、UVT/天、操作。手机行来自 T3 档位；S1 位、Pro 位、Rack 位各显示当前绑定商品和编号，可点「更换选品」从在售实物商品里选一件，确认后提交审批。
  - 审批前后的影响按对比位写：S1 位、Pro 位原商品可用时，批准前原商品照常显示，标「待审批，原商品仍生效」；原商品不可用或没选商品时，批准前这一位仍不显示，标「待审批，这一位仍不显示」，批准后 App 重新显示这一位。Rack 位目前不在 App 新用户引导里显示，批准后只更新绑定。
  - 审批有结论后标「原审批已批准」等，在上方点「准备新变更」后才能再次更换。按原操作重试时查到原审批已有结论，只提示结论和审批单号（如「审批单 … 已批准」），不再说已提交；重新读取失败时沿用页面的读取错误提示。
  - 发起和重试需要手机算力配置修改、商品目录查看和审批发起权限，另需审批查看或专用提案权限；没有手机算力配置修改权或审批发起权时不显示操作列，只缺商品目录查看权时按钮禁用并写原因。批准人须有批准权限和手机算力配置查看权限。
  - 商品下架或收益不完整的行只写绑定编号（这时系统回的名称可能是这一位的旧名，不显示），两列金额合成一句注意色结论：S1 位、Pro 位写「商品不可用，App 引导暂不显示」，Rack 位只写「商品不可用」；没选商品时 S1／Pro 位写「未选商品，App 引导暂不显示」，Rack 位写「请选一件在售商品」。原因在问号里，仍可更换；不影响其他行和手机行。可选商品加载中、没有可替换商品时按钮禁用并写原因；加载失败时面板顶部提示并可重试。
- **错误说明。** 九个后端错误码都有中文说明（见 `lib/admin/error-messages.ts`）。
