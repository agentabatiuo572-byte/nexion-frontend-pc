# B30 角色菜单与操作权限

PC 依据登录会话的有效菜单显示侧栏和可达页面，依据操作对应的权限码显示按钮。后端对每次读取、导出和提交独立鉴权。

| 页面 | 授权后表现 |
| --- | --- |
| C1 用户搜索 | 持有 `user_c1_export` 才显示「导出名单」。超管、只读审计和增长运营可按现有筛选和理由下载脱敏名单。风控的账户注销操作权限与名单导出分开。 |
| E4 订单进度 | 财务主管通过有效 E4 菜单和读权查看订单。退款入口认 `device_e4_order_refund`，仍按订单状态、后端退款检查和 A2 审批执行。增长运营保留已有的订单读取。 |
| H4 新版促销 | 增长运营可查看活动与批准政策、新建或编辑草稿、试算、提交审核，并读取奖励与报表。审核、发布、暂停恢复、终止归档、奖励处置和报表导出分别按对应权限码显示。获授权的操作仍受活动或奖励状态限制。 |
| A3、B1/B2、M3 | A3、B1/B2 与 M3 跟随有效菜单。财务、财务主管、增长运营和风控收回 A3，配置运营与内容运营收回 B1/B2，风控和只读审计收回 M3。 |
| A6 角色管理 | 配置运营的列表与详情说明为「查看运营总览的部分页面」，只读审计为「全域只读，可导出脱敏文件」。详情备注和编辑抽屉沿用后台提供的备注字段。 |

B1 储备对账导出认 `finance_d3_export`，应付款导出沿用 PCN-07 的双码和理由确认。E6 直接开关权和既有增长运营 A2 提案委托分别授权。
