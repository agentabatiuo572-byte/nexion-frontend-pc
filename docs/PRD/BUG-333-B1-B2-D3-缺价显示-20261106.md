# BUG-333 B1、B2、D3 缺价显示

存在 UVT 待兑付权益且最新有效价格不可用时，管理端按后端估值状态显示「暂时无法估值」。已核算的储备、非 UVT 科目金额、7／30 天到期预测继续显示。

| 页面 | 缺价显示 |
| --- | --- |
| B1 资金与应付款总览 | 按 B1 全口径估值可靠性隐藏当前覆盖率、仪表、覆盖率走势、基于该比率的告警建议、应付款总额、当前差额及其富余／不足判定。应付款构成保留科目及已知金额，UVT 金额、所有占比和构成图降级。配置口径的差额趋势独立使用净敞口接口的估值状态。 |
| B2 可用资金与应付款 | 应付款总额、兑付覆盖率、UVT 科目金额、各类占比、应付款构成图显示估值不可用。实际总应付款为零时保留「无应付款」。 |
| D3 资金储备与应付款 | 应付款总额、UVT 科目金额和各类占比显示估值不可用。净敞口估值缺失时，差额曲线显示状态提示，移除曲线颜色结论。配置未纳入远期 UVT 科目时，差额曲线仍可计算。 |

B1 当前数值读取 B 域快照的 `valuationReliable`。B2、D3 的九类应付款读取 `/api/admin/treasury/liabilities` 的估值状态及 `valued*` 字段。B1、D3 的差额趋势读取 `/api/admin/treasury/net-exposure` 的估值状态及 `valued*` 字段。两项读取只有在旧后端同时未返回 `valuationStatus` 和 `valuationReliable` 时兼容旧金额结构。发布与后端 BUG-333 同批核对版本和实际响应。

rd/wave2 合入说明：D3 保留改版四页签、独立读取权限及不画推算历史曲线的决定。缺价状态接到资金概况总额、应付款与到期的覆盖率／九类表／构成图／详情抽屉、配置口径的当前差额；全口径缺价不影响独立可算的配置口径差额。原「查不到价格按 0 算」说明改为按系统估值状态展示，说明收进提示图标。核对的后端 `origin/test`（`e4ac02a3`）尚未返回这两项接口的新估值字段，实际发布仍需对齐 BUG-333 后端版本；旧响应继续兼容，不能据此宣称旧后端已能区分缺价和真实零值。

实际验收需登录有原页面读取权限的管理员账号，分别在有效价格、缺价、恢复价格及零 UVT 应付款下进入三页，核对金额、覆盖率、走势图与保留的独立数据。另验证 D3 配置未纳入远期 UVT 时，配置口径差额可用而全口径应付款仍显示缺价，并切换已有时间范围确认同一口径。L3、CSV 和 J1 走各自范围。

2026-11-07（HD-FIX7）：D3 对账 CSV、应付款 CSV 和旧 B2 应付款导出（含原请求重试）在主读取无法估值时禁用，常显「暂时无法估值，导出的金额会低报，等价格恢复后再导。」。价格恢复并刷新后恢复原导出流程。`origin/test 4d964112` 的两个 CSV payload 仍使用兼容金额字段，本轮不修改 Java；此保护不代表后端 CSV 已修复。D3 可用储备、储备组成与其他资产说明统一：其他高流动资产暂不参与储备计算。
