# BE-23 管理端数值输入边界

依据 T14 和已确认的 D3、E1、H4 旧活动和 H7 表单调整。

- 资金储备与应付款的「储备注入登记」在打开确认前检查金额最多两位小数，超精度给出提示。合法输入按原值提交，并保留结果未知时的原操作键。
- 商品管理的「调整 App 组合购阶梯折扣」三档都限制 0.01%–30%，并按件数维持不下降的顺序。通过原 A2 流程提交，历史折扣仍在卡片显示。
- 活动中心的旧「活动列表」中，「新建活动」目标值允许留空按 1，显式值为 1–1,000,000,000 的整数。统计效果仍由原选项决定。用户任务页注册月龄规则属于另一个事项。
- 代金券的新增和编辑表单限制折扣率为整数 1–99。已发券模板的类型选择显示当前值并禁用，其余合规字段继续可编辑。若发券发生在已打开的编辑框之后，后端拒绝换型，提示刷新后继续。
