# H9 首页与网络展示配置（2026-10-28）

## 模块与入口

H9 按「首页数字增长、首页网络实况、赚取页任务中心、全球网络、设备预估排名、历史估算」集中配置。每个模块只展示相关输入、说明与保存按钮；切换模块保留未保存草稿。刷新及保存不清空其他模块的草稿。

介绍页在线设备/累计已发放继续读取首页数字增长；首页网络实况的注册人数读取注册基数与增长规则，在线设备与介绍页共用当前批次；设备预估排名仍按独立排名配置计算。真实设备、余额和任务不受这些展示设置影响。

设备预估排名的表格、开关、输入、帮助和底部操作统一使用 H 域样式。

## 赚取页任务中心（2026-11-03）

「首页与网络展示设置」→「赚取页任务中心」提供一项「全球作业基座」：

| 配置 | 合法范围 | 说明 |
|---|---|---|
| 全球作业基座 | 留空，或 0–100000000 整数（个） | 留空 = 不发布 |

- 发布后，App / H5 Lite 赚取页任务中心「N 个全球作业进行中」显示真实进行中作业数 + 基座；留空保存表示不发布（清除），只显示真实作业数。只用于展示，不参与任务派发、结算或资金。
- 输入非数字、小数或超出范围时就地提示，不能保存。保存沿用 H9 原有确认：改动前后值对比、填写理由、版本校验与审计。
- H9 管理接口的 `values.activeJobsBase` 与 App、H5 Lite 读取的 `publicStats.activeJobsBase` 表示同一个发布值。新旧记录默认均为 null。保存 0 是发布零，显式保存 null 是清除，旧客户端省略该字段时保留原值。真实作业数仍取首页概览的 `onGrid.activeJobs`，赚取页与地球页只加一次基座。

## 全球网络

全球网络继续明确标识「模拟数据」。固定的8个城市、坐标与翻译属于静态内容。App/H5 不内置数值回退：无有效配置时数值显示占位，地图和城市入口仍保留；读取新配置后更新指标。动画计时器不重复请求接口，隐藏页面暂停采样，恢复按当前时间与最新配置显示。

全球网络与首页共用同一个配置入口。在线节点总数取「首页数字增长」的在线设备，与介绍页、网络脉搏一致。进行中任务总数取赚取页任务中心的显示值。H9「全球网络」配置这两个总数在 8 个中心的分布，以及吞吐、延迟和数据变化间隔。

| 配置 | 合法范围 |
|---|---|
| 数据变化间隔 | 1–86400秒，最多3位小数；存储为整数毫秒 |
| 每任务小时处理量上下限 | 0–10000，下限≤上限，最多6位小数 |
| 延迟浮动上限 | 0–60000整数毫秒 |
| 每中心分布比例 | 0–100%，最多2位小数；8 个中心合计必须等于 100% |
| 每中心基础延迟 | 0–60000整数毫秒 |

8个中心必须完整且无重复：新加坡、东京、胡志明市、伦敦、巴黎、法兰克福、纽约、圣何塞。页面在分布比例下方显示实时合计，合计不是 100% 时就地提示且不能保存。确认弹窗列出各中心比例与基础延迟的前后值。

节点数、节点浮动上限和并发任务占比上下限已不影响展示，页面不再提供输入；后端仍返回时保存按当前已保存值原样回传。

H9 管理接口与 App 公开配置均返回 `globeDisplay.centers[].sharePct`。启动迁移按旧节点数占比分配至 0.01%，余数优先分给小数余数较大的中心；八个旧节点数全为零时各分 12.50%。再次执行迁移会保留已经发布的比例。旧客户端只提交节点数或调整延迟时，沿用当前已发布比例。

原全球网络基线（5400ms、处理量2.2–3.8、延迟浮动6ms；各中心基础延迟 18、22、26、16、20、14、24、17 毫秒）保持；原各中心节点基数 236000、253000、163000、249000、208000、217000、316000、284000 由后端 B22 换算为默认分布比例。不隐式开启其他模块。

## 保存、权限与兼容

每次保存只合并当前模块草稿和最新已保存值；仍通过 H9 原有权限、版本校验、理由确认、幂等与审计。设备排名沿用其独立接口与版本。其他模块若有未保存修改且服务端同字段发生变化，保留草稿并提示刷新，不覆盖他人设置。保存失败不宣称生效，刷新失败保留已有内容。

全球网络配置使用现有 H9 聚合内的 `globeDisplay` 字段，不新增资金配置或通用缓存。旧记录由后端补足原展示基线；旧客户端省略此字段时保留已保存配置。旧客户端重试使用原 H9 指纹，避免升级后误判同一幂等请求。

## 首页网络动态恢复（2026-10-30）

首页网络动态在线数统一读取 H9 networkPulse.onlineDevices；右侧每秒金额读取 H9 已发放批次相邻秒增量，暂停/未知/失败分别处理。客户列表继续既有首页投影。详见 [本轮契约](H9-首页网络动态展示恢复-20261030.md)。
