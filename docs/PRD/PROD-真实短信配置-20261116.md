# PROD 真实短信配置

日期：2026-11-16。依据：用户要求仅在生产环境启用真实短信，供正式包使用；本次不做手机号实收测试。

## 生效规则

| 后端环境 | 真实短信策略 |
| --- | --- |
| `prod` | `application-prod.yml` 将 `nexgrid.sms.itnio.enabled` 默认设为 `true`，使用既有 ITNIO 服务。可通过 `NEXGRID_SMS_ITNIO_ENABLED=false` 显式停用。 |
| 本地开发 | 通用配置仍默认关闭真实短信，保留既有显式启用方式与中国号码测试固定码规则。 |
| 公共 TEST | 继续由发布策略固定 `nexgrid.sms.itnio.enabled=false`，本次不改变。 |

正式包必须连接已发布本次后端配置、以单一 `prod` profile 运行的生产后端。仅执行 App 正式打包不会更改远程后端的短信开关；部署中的环境变量、JVM 参数或命令行若显式关闭短信，应由发布时核对并处理。

真实发送继续使用部署安全配置中的 API key、API secret、App ID 及供应商可用模板，不将凭据打入 App 或提交到仓库。凭据缺失或供应商拒绝时返回现有发送失败结果，生产环境不回退到固定验证码。

区号范围保持现状：`+84` 走 ITNIO；生产 `+86` 不开放真实短信，开发／测试固定码仅在既有条件满足时可用。登录、注册、找回密码及安全验证继续共用原投递链路，频控和验证码生命周期不变。
