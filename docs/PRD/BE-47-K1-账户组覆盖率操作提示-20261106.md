# K1 账户组处置和放宽规则提示

- K1 的「解除误判」和「判定为正常」在确认框中说明批准时才检查兑付覆盖率。低于红线时，审批单继续待处理，账户组状态和提现限制保持原样。
- A2 按服务端工单标记显示这两种操作的批准提示。详情和执行确认使用同一口径，按当前兑付覆盖率决定能否执行。
- K1 的三个账号上限编辑框说明调大时保存前检查覆盖率。IP 允许名单说明新增、重新启用或延长有效期时需要检查。两种放宽都保留既有待判定组的提现限制，等待人工处置。

## 放宽收益审核规则与人工放行收益（BUG-286）

- 调高收益待审核或建议冻结起点，以及人工放行一笔待审核或已锁定收益，均从 K1 发起 A2 审批。待审时原参数或收益状态保持，另一位有权限的超管批准后才生效。
- 结果未知时，K1 按原提案的命令号查回同一张 A2 票。放宽参数批准后回读新值和版本。人工放行批准后回读该笔收益的可提现状态，净额不变。
