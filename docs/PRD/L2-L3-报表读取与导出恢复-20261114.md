# L2/L3 报表读取与导出恢复

2026-11-14；后端固定111e00cd；对应开发落地规格4.14、L2/L3重构说明。

## L2 用户转化与留存

同一注册用户群按注册、首购、复投或第二笔购买、提交提现逐级严格晚于前一步。第3步取两个候选中更早者。L2与B3共用后三步非空转化率的最小值计算，同值取较早步骤；它不是掉人数最大的步骤，也不是因果诊断。B3现有“流失最多”文字需视觉收窄。

后端有留存和试用读模型，但app.dau与trial.claim_sheet_shown仍未找到生产端。两个来源开关保持false，不显示成0、不用L6访问或trial.started代替。其他主链、筛选、渠道首购指标、聚合导出、本机视图保持现行合同。聚合导出重新取执行时事实并保存快照，CSV仍可能包含未接事件算出的留存率，确认框继续提示不可使用。

## L3 财务报表

四类收入按来源汇总，提现按事件计数且确认除以申请可超过100%，空分母保持null。自然月和季的上期是前一自然周期，天数不一定相同；页面“同样长”文字待视觉更正。储备、负债、覆盖率、7与30日到期来自一次权威资金快照，不随页面周期改变。

资金快照必须给valuationReliable、valuationStatus、nullable valuedTotalUsdt、各科目的valuedAmountUsdt和valuedShare；可靠时严格校验数值，缺价时只允许UVT金额为空且所有占比为空。不从旧overview中的可靠性标记推断当前资金状态，不把null转0。页面使用B1、D3共用常量“暂时无法估值”。每日到期保留原始四项、trialStressIncluded与cumulativeUsdt；只有后端累计为0才解释为没有到期。覆盖天数原样取后端，不用三类金额和999、0哨兵推断无到期。

走势是8点每3小时的重建数据（当时储备除以现在负债），不是12周历史；后端越线固定空。质押到期只有预计利息，不含锁定本金。7、30日三类图与30日7、7、7、9分组沿用现有界面；逐日图没有备好的视觉位置，不新增图形。

## 导出合同

L2聚合、L3汇总均POST /api/admin/bi/reports并由L_BI_REPORT_CREATE去重，带理由及审计。两者是带审计的只读操作，按B4-PD02不建立R1恢复锁。L3汇总是生成时资金概览、九科目、7日到期、账单分类计数快照，不含四收入、周期提现、30日完整图；不受周期或注册月筛选影响。

L3高敏明细精确要求bi_l3_export_detail，不要求汇总权限；请求固定HIGH_PII、MASKED，日期取已读周期，九字段至少一项、按选择顺序，不带注册业务月。使用人、工单、理由仍按现行规则填写。只隐藏用户编码首2末2（短码***），业务编号和金额原值；最多100000行，超出拒绝。提交即生成快照并PENDING_CONFIRM，另一位有bi_l5_task_approve的管理员放行，不能自批；不是A2提案，没有command、sourceDomain、obj、target审批信封。

敏感创建前将原完整请求（含操作者、理由）、命令号、首次时间与24h截止写入sessionStorage，校验真正落盘后才发。同标签页刷新恢复，原确认输入冻结。原号原body重发，过期只查询；明确业务拒绝解除，401、403、408、425、429及IDEMPOTENCY_*保留。查询失败、404不等于创建被拒绝。按原号创建回放只证明建过单；得到reportId后按GET /api/admin/bi/exports/{id}读取当前状态，只有当前待批准才显示待放行。查询失败保留原记录并禁重复创建；无L5读权只保留核对记录与找有权同事提示，不增加权限、不跳进不可达页面。后端无按原命令号只读查询，丢回包且无reportId时只能在L5或请同事核对；本地不凭列表描述自动结案。
