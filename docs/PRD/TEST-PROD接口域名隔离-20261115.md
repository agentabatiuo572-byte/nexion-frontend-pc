# TEST/PROD接口域名隔离

用户要求TEST接口使用https://api-test.uvel.ai，PROD接口使用https://api.uvel.ai。新增api-test的Cloudflare代理A记录指向18.143.87.230，生产api保留35.78.230.145，不合并或发布main。

App新增.env.test及build:h5:test；.env.production固定生产API。本机开发仍使用现有开发代理。TEST CI必须使用test模式并去掉旧IP覆盖。页面布局、文字和业务动作不调整，本次是等价接口地址配置。

PC浏览器保留同源/api BFF和HttpOnly Cookie；既有路由读取NEXION_BACKEND_URL，因此由部署配置将TEST BFF上游设为api-test、PROD为api。config/api.test.env.example及api.production.env.example提供非敏感模板，不将生产URL作为TEST构建或运行默认值。API域名的/api/admin路径直接进入Java，避免再次路由到PC BFF形成循环。

TEST域名需专用HTTPS虚拟主机、可信Cloudflare源站证书、正确的代理来源与客户端IP处理。保留原TEST访问限制，明确CORS及回调允许域名；api-test自身并非HDPAY收银台域名，不能因此把第三方付款页校验视为已通过。App使用同域api-test/app入口验收，PC继续通过原PC入口的同源BFF访问新API上游。

以实际网络、3778登录/会话刷新/钱包和充值提现只读页面，以及管理端现有登录态读取验证。构建、发布和业务验收分别记录；不建真实订单、不发放奖励、不实际升级。当前文档为执行契约，不提前表示上述验收已完成。

2026-11-16 TEST实景验收：App Jenkins#8（5dc7f206）、PC Jenkins#3（7bd7b80f）已发布。3778登录及刷新200、充值汇率和银行卡入口、三种USDT提现网络读取正常；PC会话、总览与D1读取成功。本轮没有创建订单。原有创世节点/换购/资金准备的未就绪响应不在本轮域名修复范围。

Cloudflare Bot Fight会质询服务器请求，精确Skip无法解除；本轮临时Skip已删除，未降低全站或生产防护。仅uvel-pc服务通过systemd BindReadOnlyPaths使用专用hosts，将api-test.uvel.ai解析到127.0.0.1，NODE_EXTRA_CA_CERTS使用官方Cloudflare Origin RSA根验证源站证书；系统全局解析及浏览器外部Cloudflare访问不变。配置位于/etc/uvel-pc与uvel-pc.service.d/api-test.conf。

新域名Nginx保留访问限制，清除Forwarded并固定转发Host/Port，只有可信CF代理传递真实IP、只有本机BFF传递操作员IP。伪造转发头的App登录仍记录真实客户端IP。TLS入口对刷新Cookie增加Secure，实际保持HttpOnly、host-only与SameSite=Strict。CORS、WebSocket与HDPAY回调允许主机包含api-test；HDPAY实际回调基础地址保留已登记IP，第三方付款页允许主机仍为api.hdpayadmin.com。是否能打开真实收银台，仍需下一笔用户订单的真实返回data验证，不能以API域名就绪代替。
