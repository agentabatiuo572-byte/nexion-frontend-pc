#### [FEAT-HOME02] 前端 · 网络脉搏三项可配与真实排名

**① 用户故事**

- 作为浏览首页的用户,我想要看到平台规模与我自己的位置,以便判断这个网络是否活跃、我处在什么水平。
- 作为已激活设备的用户,我想要我的排名真实反映我投入的算力,以便加算力时能看到排名前进、获得正反馈。
- 作为尚未激活任何设备的用户,我想要清楚知道我还没进入排名以及怎样才能进入,以便知道下一步做什么。
- 作为运营,我想要在后台调整对外公布的平台数据,以便在不同阶段呈现匹配的规模,而不必改代码发版。

**② 验收(GWT)+ 异常路径**

- 阳光路径(版面):Given 用户打开首页,When 网络脉搏板块渲染,Then 只显示三格——**注册用户 / 在线设备 / 你的排名**;「今日支付」格及其副文本完全消失,三格等宽排布无空位;**板块条头的实时支付流数字与其滚动动画一并消失**,条头只保留板块标题与「实时」标记,删除后无空行、无残留分隔线。
- 阳光路径(可配生效):Given 运营在后台调整任一项参数,When 用户下次进入首页(或下拉刷新),Then 展示值随之变化,无需发版;数值与副文本口径一致(如在线设备变化时,依赖同一锚的其它页面同步变化,不打架)。
- 阳光路径(真实排名):Given 用户已激活 N 台设备,When 脉搏卡渲染,Then「你的排名」= 该账号全部已激活设备**有效算力之和**在「真实 + 虚拟」总人口中的位次;同一算力与同一配置下**结果确定**(多次刷新不跳动)。
- 阳光路径(排名前进):Given 用户新增或升级设备使总算力上升,When 排名重算,Then 名次**只可能前进或持平,永不倒退**(算力单调 → 排名单调)。
- 异常1(未激活设备 / 零算力):Given 用户总算力为 0,When 渲染排名格,Then 显示「未上榜」+ 一句引导(激活设备后进入排名),**禁**显示一个巨大的假名次,**禁**空白。
- 异常2(配置拉取失败):Given 平台展示配置拉不到,When 渲染脉搏卡,Then 三格显示骨架并在超时后转为「数据更新中」占位 + 重试,**禁**回退到写死数字冒充真实数据,**禁**显示 0 或 NaN。
- 异常3(参数非法):Given 后台配置出现非法值(负数 / 非数值 / 虚拟人口为 0 但分位表要求非空 / 分位表不单调),When 前端消费,Then 该项判为不可用走异常2 的占位路径,并保证其它项不受牵连(单项坏不拖垮整块)。
- 异常4(24h 变化未知):Given 用户首次进入或无 24 小时前的排名快照,When 渲染排名副文本,Then **不显示**变化箭头与数字(留空或显示当前名次即可),禁编造「↑12」。
- 异常5(极端算力):Given 用户算力高于分位表最高档,When 计算名次,Then 取表内最优档对应位次为下限(不出现「第 1 名」这类不可信结果);算力异常大(超合理上限)按最高档处理并不影响其它用户口径。
- 异常6(数字超长):Given 注册用户或在线设备被配成很大的数,When 渲染,Then 按紧凑单位缩写(如 1.42M / 28.4K)且不撑破卡片、不换行断字。
