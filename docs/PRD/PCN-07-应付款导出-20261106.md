# PCN-07 应付款导出

| 入口 | 导出权限 | 操作 |
| --- | --- | --- |
| B2「可用资金与应付款」的「导出负债 CSV」 | `overview_b2_export` 或 `finance_d3_export` | 输入去掉首尾空白后为 8–200 字的理由，确认后下载应付款明细。 |
| D3「资金储备与应付款」的「导出应付款 CSV」 | `overview_b2_export` 或 `finance_d3_export` | 使用原有确认框和同一应付款导出接口。 |
| D3「导出对账 CSV」 | `finance_d3_export` | 继续导出储备与应付款对账数据。 |

两个应付款入口使用 `POST /api/admin/treasury/liabilities/export`，提交理由与 `Idempotency-Key`，由服务端记录真实操作者和审计。B2 收到结果未知时保留命令号，同一管理员以同一理由重试会重用命令号。确定成功后可发起新的导出。权限不足的操作在页面中不可用，服务端仍独立校验权限。

本条更新 PRD v1 的 B2 和 D3 应付款导出契约。页面读取权限沿用现行规则。BE-36 的旧无理由 GET 接口退役与本条同批发布。
