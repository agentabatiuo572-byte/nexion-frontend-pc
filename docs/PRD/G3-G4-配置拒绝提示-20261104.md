# UVT价格管理与创世节点配置失败提示（BUG-278）

已有配置操作被拒绝或相关数据无法加载时，保留当前流程的失败状态，显示具体原因与下一步。这里不开放销售、定价或已退役产品入口；既有权限和审批检查保留。

| 系统原因 | 运营可见的原因与处理方式 |
|---|---|
| GENESIS_SUPPLY_REQUIRES_TIER_UPDATE | 节点总量必须大于最后销售档位的起点；在「创世节点销售与收益」核对档位，调高总量或先调整最后一档（BUG-298，Jason）。 |
| GENESIS_TIER_BELOW_SOLD | 最后一档总量小于已售数量；核对已售数量并调高最后一档上限。 |
| GENESIS_TIER_INVALID | 档位边界、价格或总量不合法；填写大于起点的上限、正整数价格并核对总量范围。 |
| GENESIS_SUPPLY_CONFLICT | 保存时总量配置变化；刷新「创世节点销售与收益」核对最新总量和档位后重试。 |
| B1_COVERAGE_UNRELIABLE | 覆盖率无法可靠计算，操作未获放行；到「资金储备与应付款」核对数据，恢复后再提交。 |
| G3_WEEKLY_CURVE_INVALID | 当前七天曲线不完整或格式异常；刷新「UVT价格管理」核对，持续异常联系值班人员修复配置。 |
