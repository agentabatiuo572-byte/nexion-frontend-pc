# BE-08 J1 业务开关恢复审批

J1 单项和批量关停在确认后即时执行。已关停且符合原恢复前置条件的业务显示「恢复」，确认框写明「提交 A2 审批，批准后生效」。提交成功显示申请编号，业务仍显示「已关停」。有权发起恢复审批的管理员可在结果未知时核对原申请，刷新后仍使用原命令号及原请求。

A2 将 J1 恢复申请标为应急，排在其他待办前。发起人不能执行自己申请。另一位有 A2 审批及 J1 恢复权限的超级管理员可以批准或驳回。资金业务批准时重新检查覆盖率，检查失败仍保留待批工单。试用开关继续免查覆盖率。A2 原有其他工单的排序和权限沿用现有规则。

J1 的覆盖率卡使用服务端估值可靠性及恢复判定，健康线显示服务端实际健康线。百分比展示及其与红线的比较不自行放行资金恢复。估值不可靠或缺少上述判定时，当前覆盖率显示「暂时无法判断」，资金业务的新恢复入口禁用，原恢复申请仍可核对；若按原键未查到申请，保留该键并提示当前只能核对，不继续提交资金恢复，待服务端允许恢复后才可沿原键续原请求。资金检查结论仅在服务端允许恢复时显示绿色勾号，受阻或无法判断使用警示标识，禁用的恢复按钮使用中性样式。关停和无需备付金检查的业务继续各自权限与流程（2026-11-06，BUG-313）。

验收从 J1 确认关停与提案，在 A2 核对置顶、发起人限制和另一位管理员执行，再回到 J1 确认最终状态。覆盖率变化与提交结果未知分别核对未恢复和原单可查询。
