# 运营后台内容语言

2026-11-18，PC 改版线合入 PR #68 (`b1078ad8f`)，运营规则以 `proto-backend` 的 `3ea9ca18` 为准。

## 编辑、保存与使用公开快照

- 英文始终必填。中文与越南语由 A3 的「发布时必填的语言」设置决定。系统从未保存时只要求英文。编辑器打开和提交新改动时读取设置，读取失败按三语必填。这个设置独立于 App 界面语言开关。
- 新建或保存时，同一内容下未选的语言整组留空，用各字段对应的英文提交。只填一部分时须补齐。打开编辑器时，某个选填语言的已存整组与英文相同，则显示为空。必填语言中非空的英文副本仍是已存内容。
- 发布、排期和回滚核对该操作的已存版本。I4 版块与 I5 披露的发布或生效门核对已存英文。I2 发布和 I6 词条发布仍校验已存快照的完整性与变量。促销在送审时检查候选，有编辑权限时按原修订先保存补齐的副本，送审权限单独有效。
- 内容写入核对目标、版本与实际提交值。超时、原命令处理中、结果未知、回执无法核对时保留原命令。重试沿用原请求和编号。I1 文案发布或删除、I4/I7 草稿删除、I5 草稿写入的回执已确认后，仍待读回时只查对应版本或原结果。

| 入口 | 规则与绑定 |
|---|---|
| A3 系统配置 | 既有重新勾选流程处理无法读取的语言清单。官方安装说明支持英文、中文、越南语。开启下载时英文必填，中文按本次勾选校验或补入英文，越南语始终选填。暂停下载时各语言可独立预存或清空。保存核对语言清单和实际提交的说明。 |
| H3 用户任务管理 | `3ea9ca18` 的 `transitionMission` 保留状态、完成条件和资格校验。PC test 的 MISSION 名称门依赖 `contentLocales.mission`，真库样本没有这组文案，改版入口按现有任务合同操作。 |
| H4 活动中心 | 活动表优先使用 `copyReadiness` 和 `appRewardNames`。缺少这些事实时沿用原计算与现有未知状态。文案按格保存，用原始已存值作 CAS。草稿选填译文可从原编辑确认入口显式清空。活动规则与抽奖保留 A2 入口。 |
| H4 商城促销与抽奖 | 促销公开说明允许稀疏草稿，送审核对标题和条款，试算结果绑定活动、候选版本、修订和合同哈希。抽奖按轮次标题和全部奖项名判断各语言整组。 |
| I1、I2、I3 | 分别按单条文案或一对标题正文检查。保留现有占位符、退役跳转和长度约束。I3 同步现有英文按钮译文覆盖。 |
| I4 信任中心 | 草稿按全部可翻译字段组检查。已存版问题和发布确认使用同一个「缺英文」判定与筛选键。 |
| I5 法律条款与风险披露 | 保存以总文、七章标题和正文为一个语言组。写入后按实际版本与哈希读回。发布和切换可选版本看已存英语。发布确认框和「草稿和待审批」的「看改动」对照总文和七章，只改总文时写明（BUG-473）。 |
| I6、I7 多语言与课程 | 单词条和修复按英语核对占位符。课程把标题、正文、题干与每个选项作为同一组。在线课程可见性按 App 的基础和附加语言取值。带奖励发布及回滚沿用 A2。 |
| M4、M5 专属客服 | 新建 FAQ 默认 `en-US`。话术与即时回复以英文为原文，发布要求先发布对应英文词条。欢迎语按语言设置保存并按实际内容核对回执。 |
