# PC 平台代币名称统一 UVT

日期：2026-10-26。依据：用户要求检查 PC 代币名称，不符合的全部改为 UVT，避免误改其他对象。

本规格补充术语词典 TERM-002，适用于正式 PC 的导航、列表、详情、统计、配置、表单选项、操作确认及下载报表（含后端生成的展示表头与单位）。旧 PRD 中作为平台代币显示名使用的 NEX 或 UVEL，以本条为准。

## 名称与数据边界

| 对象 | PC 展示 | 数据处理 |
|---|---|---|
| 平台代币及其数量、奖励、余额、价格、抵扣、释放、负债 | UVT | 既有接口、枚举及账本代码 NEX，以及 nex / rewardNex 等字段、配置键和路径保持原契约 |
| 平台品牌、产品名称中的 UVEL | UVEL | 不将公司、平台、商品、客服或券名称中的品牌替换为币种 |
| USDT、BNB、BSC/BEP20 等其他资产或网络 | 原名称 | 不改变其币种、网络、单位、金额或参数 |
| 登录 token、AI 任务 token | 原有业务名称 | 不属于平台代币名称统一范围 |
| 用户自填文本、凭证编号、原始审计及账本标识 | 保留原事实 | 不进行全量字符串替换，不重写历史账本或业务配置 |

展示转换只发生在明确的资产字段或由系统控制的展示文案。选项显示 UVT 时，其 value 仍使用后端支持的 NEX；筛选、保存、查询和导出请求继续遵守原资产契约，不新增 UVT 账本资产，不转换或重算金额。

## 覆盖与验收

1. 全局导航、搜索、模块标题与帮助说明中的平台币名为 UVT。
2. 用户资产调整、余额、流水、财务报表、兑换、行情、设备奖励、等级奖励、签到、任务、活动、新人礼、邀请奖励及客服业绩中的平台币单位为 UVT。
3. 表单和筛选的可见标签为 UVT，读取原 NEX 数据后仍选中原资产；请求保留 NEX，USDT 对照项不变。
4. 平台页头保持 UVEL；品牌名称、用户内容、协议字段、链网络和金额无误改。
5. 按本轮测试计划进行代码边界检查及实际页面操作；构建成功、TEST 部署和页面验收分别记录。生产发布须另获批准。
6. L4 等后端生成报表的人类可读表头及单位也使用 UVT，例如“期间产出 UVT”“UVT 应付款”；`dailyYieldNex`、`nex_payable` 等机器字段或原始资产代码不改，不改变导出数值。
