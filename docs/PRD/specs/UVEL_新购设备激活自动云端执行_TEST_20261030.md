# 新购及升级置换设备激活后自动云端执行（TEST）

日期：2026-10-30 Asia/Tokyo。依据用户本轮要求：后续新买设备不限Cloud Share，激活后自动接入云端任务、回传结果并结算，先在TEST验证完整流程。本轮输入沿用明确TEST的真实BGE-M3文本；不是客户业务任务源或物理设备本机算力证明。

## 范围与接入

1. TEST部署开启自动托管后，正常付款订单（来源ORDER）及合法升级置换成交（来源TRADE_IN）产生、仍有效持有且已激活的硬件实例自动发现并接入，不要求运维逐台配置设备ID或复制凭据。Cloud Share、Box S1、Box Pro/Pro v2、Rack系列使用同一流程；上架、库存、购买资格和六槽限制仍由原规则决定。
2. 实例按账号、设备ID、实例号和原订单保持独立；同款重复购买不得合并任务、执行日志或奖励。重复发现、重复激活和服务重启不得重复创建绑定或收益。
3. 正常ORDER沿用原固定起点；升级置换使用默认关闭的独立开关及新的固定起点，购买、激活、置换申请提交和完成均须不早于相应起点。已有旧执行器及未决任务不自动接管或清理。时间比较与业务写入UTC+8一致。已停用、撤销、退款、无合法成交、未激活、测试夹具、赠送或试用来源不通过自动接入。
4. 免费手机来自校准与onboarding，不是本轮新购硬件。手机原安装绑定、实际电量/网络心跳和执行会话继续独立生效，云端执行器不能伪造手机遥测。

## 派发、真实执行与结算

5. 普通购买成功自动激活，队列中的已激活设备统一显示Online；取消激活后退出队列回到仓库。云端执行通道在后台独立核验实际心跳、输入和任务归属，产品Online标签不替代执行证明。普通页面或旧派发器不得抢先创建无执行输入的任务。
6. 路由取原E2有效任务池与云执行器实际支持模型的交集，同时遵守原设备显存、任务状态及暂停条件。本轮部署的真实模型为BGE-M3，不把图像、视频、LLM等任务改名冒充该模型，不修改设备显存。
7. 每笔任务固定输入、输入hash、模型摘要、执行身份和实例。执行器真实推理并提交向量产物；后端重新校验hash并以同版本独立推理核验，才允许完成。
8. 奖励取原任务报价及E3设备容量规则，保留任务冷却、锁、日界及Cloud Share日UVT规则。完成、回执、钱包流水和收益事件使用原事务，一次结果只结算一次；激活、估时100%或Online本身不产生收益。
9. 多实例公平调度；无可执行任务或仍在冷却时等待，不虚构任务。某实例失权、异常或有未决请求时隔离该实例，不阻塞其他实例，也不通过心跳掩盖未决状态。

## 生命周期与恢复

10. 领取、心跳、完成均重新核验权威账号和实例权益。停用/待停用、退款撤销、机房暂停沿用原有“停止新派发/完成当前任务”规则，不自行改变既有结算约定。
11. 每实例保存独立持久请求意图。已发送但响应未知时先读取匹配回执；没有读到回执不等于可以重新回传。未知状态不得清空或改绑；历史回执允许在实例停用后只读对账。
12. 仅TEST/dev环境可启用该执行域，执行凭据不下发App/H5，不允许普通用户或管理员登录态代替执行器。生产启用及main合并须另行批准。

13. 升级置换须联合完成的申请、兼容订单、PAID/COMPLETED订单、唯一新实例及单行商品明细核验。账号、新旧实例、商品、订单和服务端生成的成交标识必须关联一致；抵扣、钱包实付与原价快照守恒。原业务允许全额抵扣时，零实付不被误拒；不重新用当前商品价格计算历史成交资格。
14. 回收旧机的升级置换沿用原交付位置：旧机已激活则新机沿原槽激活；旧机在仓库则新机先入仓且不派任务、不产生收益，之后正常激活才自动接入。后者订单可保留INVENTORY，接入以新设备真实激活状态为准，不能要求订单字段虚假改为ACTIVATED。
15. 满槽替换保留旧机入仓、新机激活，零抵扣且原价正常付款。由独立成交标识和完整业务关联区分回收型与保留旧机型；旧机后续合法再激活或再次置换不倒停该保留旧机型新设备。不依赖会被归档的热审计记录维持长期执行资格。
16. 已确认且账号未变的结算页面，在后台只读试用资格刷新期间保留展示，避免反复闪回加载或吞掉支付点击；首次未知、读取失败或身份变化仍阻止付款。实际付款须等待成功的新权威读取，并在原单恢复、确认弹窗及新建订单前核对账号/路由、金额、试用分流和报价版本。旧请求结果未知时先恢复原单，不重复扣款。
17. 订单历史兼容带`promotionQuoteId`的促销订单`subtotalUsdt`、`discountUsdt`定点十进制字符串，实付`amountUsdt`保留原精确字符串，普通订单仍遵守原严格数值契约并拒绝非法金额。历史促销订单不得阻断同列表已成交升级置换订单的读回；结果未知时沿原幂等键恢复原单，不创建新订单或重复扣款。
