# E1 商品编辑保留未编辑属性

E1 编辑现有商品仅修改运营明确编辑的字段。服务端返回的评级 `rating`、评论数 `reviews`、内部代际 `generation`、继任商品 `supersededBy` 和换购兼容折扣 `tradeinDiscount` 随目录读取、表单转换、A2 提案和保存完整保留；不新增这些字段的编辑入口，不因仅调整库存而清零、清空或回到第一代。新建商品沿用内部代际默认值 1。

销量 `sold` 是订单生命周期计数，E1 继续展示，但 A2 命令和直接保存请求均不提交该字段；执行时由后端保留当前真实销量。修改提交携带当前商品快照的 `expectedUpdatedAt`（直接保存使用 `X-Product-Revision`）；审核执行仍按原版本冲突契约拒绝过期提案，不覆盖并发更新。

保留现有媒体预签名 URL 剔除、购买门和收益展示等后端/表单规范化规则；本次不调整它们的产品语义。验收需经真实 PC 库存编辑和 A2 审核，核对保存后上述字段与原值一致，再正常恢复库存；源码回归不代替 TEST 实景验收。
