## 商城排序

「新增／编辑商品 → 基本信息」按 E1 页面设计使用现有数字输入，「商城排序」位于生命周期右侧。「营销角标」在下一行左栏，自定义角标输入显示在同栏下方。审批确认显示调整前后的值。商城排序（`storeSortOrder`）填写 -2,147,483,648 到 2,147,483,647 之间的整数。新建默认 0，编辑回显当前值。具有现有商品编辑权限的管理员提交提案，由另一位拥有商品修改和审批批准权限的超级管理员在 A2 复核。批准后，同为精选或同为普通的商品，数值越小越靠前。同值按商品 ID 从小到大。App 和 H5 Lite 仅在「在售」应用商城排序。用户从收益目标链接进入时，仍先显示该链接推荐的在售商品。

后端通过 `storeSortOrderSupported` 声明此能力。缺少排序字段的历史提案和旧客户端更新沿用商品已有值。验收在 TEST 用两件同一精选状态的在售商品核对审批前、审批后和恢复后顺序。
