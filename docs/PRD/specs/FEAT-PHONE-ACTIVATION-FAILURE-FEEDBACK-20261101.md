# 手机算力激活原因提示与结果确认

2026-11-01。依据用户截图及当日明确要求：按实际原因补齐失败提示；槽位满明确先停用一台设备再激活；结果未确认不能直接称激活失败；使用真机调试验证，不打包。补充手机校准/激活、换机及统一六槽合同。

## 状态语义

1. 明确业务拒绝：按服务端当前原因码或原操作 FAILED 回执显示具体原因和可执行动作。次级查询或刷新失败不得覆盖已经取得的明确拒绝。
2. 结果未确认：激活提交后网络、超时、5xx、协议异常，且未取得可信成功或失败事实时，显示「激活状态待确认」与核对状态入口，不能显示「激活失败」，不能另起新激活意图。继续使用原操作标识及提交时的版本/确认快照，先查询原操作或当前手机权威状态。
3. 服务端已成功：原操作 SUCCEEDED 或当前手机权威 ACTIVE 结果按成功处理。随后本机状态保存/同步失败，只能说明「手机算力已激活，本机状态暂未同步」，提供重新同步，不重复提交激活，也不误导用户停用或换绑。
4. 激活前的资格查询失败属于前置条件未确认，不冒充已经提交或激活失败；未知原因不得通过文案猜测业务结论。不同账号、安装或旧页面的响应不得更新当前提示。

## 原因与恢复动作

| 原因 | 代表原因码 | 用户提示与动作 |
|---|---|---|
| 激活槽位已满 | CAPACITY_REPLACEMENT_REQUIRED | 明确「激活名额已满，请先停用一台设备，再激活手机算力」；可前往设备仓库处理，释放后重新检查。试用、订单预留继续计入；不能扩槽或自动停用已有设备。 |
| 尚未完成校准 | ONBOARDING_CALIBRATION_REQUIRED、ONBOARDING_CALIBRATION_NOT_FOUND | 先完成手机算力校准。 |
| 硬件待核验 | PHONE_CALIBRATION_PENDING_VERIFICATION | 当前手机尚未匹配算力规则，暂时无法激活；保留稍后再试/支持入口。 |
| 校准规则/结果版本变化 | PHONE_CALIBRATION_RULES_CHANGED、ONBOARDING_CALIBRATION_REVISION_CONFLICT | 重新读取并按需要重新校准，不重复提交旧校准版本。 |
| 禁止换机 | PHONE_REPLACEMENT_DISABLED | 当前无法更换绑定手机；联系支持核对，其他已购设备不受影响。 |
| 换机间隔不足 | PHONE_REPLACEMENT_COOLDOWN | 尚未达到允许换绑的间隔，稍后再试；不承诺未经服务端提供的具体时间。 |
| 换机次数用完 | PHONE_REPLACEMENT_LIMIT_REACHED | 本周期换机次数已用完，等待资格恢复或联系支持。 |
| 资格历史不完整 | PHONE_REPLACEMENT_HISTORY_UNKNOWN、PHONE_BINDING_TIME_UNKNOWN | 暂时无法确认换机资格，联系支持核对记录，不能当作零次换机放行。 |
| 风险暂停 | PHONE_REPLACEMENT_RISK_PAUSED | 当前换绑受到限制，联系支持；不通过普通重试解除限制。 |
| 绑定/策略/审批状态变更 | BINDING_VERSION_CHANGED、POLICY_VERSION_CHANGED、GRANT_STATE_CHANGED、PHONE_REPLACEMENT_CONFIRMATION_REQUIRED | 重新读取当前绑定、资格及策略，必要时重新明确确认；不能沿用失效快照或自动代为同意换机。 |
| 会话/安装/执行能力不符 | USER_AUTH_REQUIRED、SESSION_REPLACED、CURRENT_APP_REQUIRED、APP_SESSION_REQUIRED、INSTALLATION_MISMATCH、PHONE_INSTALLATION_ID_MISMATCH、PHONE_EXECUTION_UNSUPPORTED | 按原因提示重新登录当前手机 App、核对安装或当前版本不支持手机执行；浏览器不因此获得激活权限。 |
| 运行环境/请求或服务异常 | 环境不一致、激活请求无效、配置不可用、绑定写入/回读异常等当前可达原因 | 给出安全、可理解的当前条件未确认/服务暂不可用提示；不暴露内部配置、数据库或原始异常。提交后的未确定错误按上方待确认处理。 |

默认「请重试」仅适用于当前错误确实可通过重试恢复的分支。槽位满、需要重校准、换机限制、会话失效和待确认分别提供符合其语义的入口/按钮。中文、英文、越南文语义一致；标题、正文和按钮必须对应同一状态，旧硬件缓存不能遮盖本次明确的槽位拒绝。
