# 我的页面提现提醒统一归消息

2026-10-31用户明确决定。本条覆盖旧My提现状态卡的展示约定。

- “我的”页只保留原钱包、充值/提现/兑换操作入口及收益概览；收益概览下面不展示任何提现状态卡、最近提现、在途提现、失败/冻结/待处理条目，也不留下空壳、占位、额外间距或替代横条。所有提现状态均适用。
- 提现失败及需要用户关注或处理的提醒统一归消息中心“通知—资金”，读取原业务单据与真实事件；状态、原因、金额及实际事件时间来自权威记录。不把接口读取失败伪造成提现失败，不为消息修改提现状态或伪造新业务时间。
- 提醒中的查看/处理动作定位对应提现单号，进入该单现有详情/追踪流程；银行单继续原银行详情路由，链上单继续原追踪页。消息与原生推送深链使用同一准确单据标识；无有效原单标识时不回退到当前最新提现单，也不按标题或金额猜单。
- 读取、重复接收和旧消息路由修正不得重复创建同一业务提醒、重置已读或冒充新的业务发生。账号可见范围、消息偏好、强制通知与原推送协议保持；不因移除My卡片额外广播历史提醒。
- 钱包、账单与提现详情保留原交易历史和查询能力；审核、退款、资金占用、幂等及用户操作资格仍由服务端原状态机决定。点击消息只查看/导航，不自动重提提现或执行资金命令。
- 配置/钱包/收益/提现列表的接口读取错误仍沿原My页尾恢复区，不在收益概览和常用功能之间新增错误卡。消息已读、分类、分页及返回遵守原消息中心规则。

验收：已有失败提现账号进入My收益区无卡；到资金消息可读真实提醒并进入原单，返回My仍无卡；其他提现状态同样不渲染该区域。TEST发布、同源装机及真机结果以本轮验收记录为准，不以文档或构建代替业务验收。
