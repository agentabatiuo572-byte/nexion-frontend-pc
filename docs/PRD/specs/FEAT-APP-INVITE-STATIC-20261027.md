# 邀请卡静态展示

本条按用户最新要求更新团队主邀请卡，取代先前该卡暖刷新时隐藏静态说明的展示预期；其他页面及规则、记录弹层不由本条变更。

- 海报、邀请码、链接三个静态工具及主“邀请好友”按钮的图标和文字在首次读取及后台刷新时保持正常视觉，不因邀请码尚未就绪整体降灰。原禁用语义、键盘焦点限制及处理函数继续只认可当前有效邀请码和分享链接；视觉稳定不能复制旧码、打开海报或发起分享。
- “每位好友达标后可获”及对应英文、越南文作为通用静态说明，在初次未知及已启用结果的暖刷新时持续显示，不随金额或邀请码就绪消失重现。未知金额仍为“—”，不补零、不生成收益事实或给予资格。
- 同一作用域最后确认奖励关闭时，继续显示原关闭说明，不在暖读取或错误重试过程中替换成泛化奖励说明。真实错误优先显示原失败反馈和重试；新结果可替换原状态。账号、绑定、环境及目录失效同步清除旧展示上下文，继承原编译期环境重建合同。
- 该局部只读说明状态不进入任何奖励、佣金、分享或资金命令。原请求及过期响应围栏、当前邀请码及按钮处理函数保持；真实错误继续提供明确反馈和重试。真实业务状态变化或错误文案可能自然改变卡片高度，不把这些状态签为像素冻结。
- 不修改滚动控制器。本轮旧回顶/下拉视频存在并行操作，不作为无操作自动回顶或控制器缺陷的证明。
