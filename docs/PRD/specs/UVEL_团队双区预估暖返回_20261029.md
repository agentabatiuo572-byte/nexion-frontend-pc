# 团队双区贡献预估的暖返回展示

对应禅道 #679。Team 经“我的”或客服返回同账号、绑定、语言和运行环境时，已确认的双区贡献奖励预估及 A/B 数值在后台重读期间持续显示，新结果原位替换，不因实时读数暂时清空改为“—”，不新增占流加载说明。沿用当前字段、格式、单位及三语文案，不改变计算口径。合法零值显示零；首次没有确认结果仍显示未知。

目录只变更版本或发布元数据，或商品 imageUrl 变化（包括图片短链续签），且目录来源、命名空间及商品业务内容不变时，不废弃同作用域的双区展示。商品价格、库存、门槛、blocked 等业务内容或目录来源/命名空间发生变化，即使版本字串相同，也立即清除旧展示。

只在页内保留 estimatedAmountUsdt、trackA、trackB 三个只读数值，不回填共享 store 的实时快照，不授予结算、领取、交易、购买、手机操作或其他权限。只读详情入口保持，进入后的实时读取、资格、暂停、错误及操作规则独立判断，不传递展示快照作为授权。

真实双区读取失败立即清为未知，重试等待不能恢复失败前的旧值，只有新确认成功才能恢复。账号、同账号重新绑定、语言、环境或接口地址变化，以及外部业务写入、失权、目录作用域失效时立即废弃旧展示；旧请求不能回填新作用域。普通同作用域 pending 可保持，新确认零值必须正确替换旧值。

团队激励池已有同作用域 loading 保持、真实 hold/error 清理的规则继续保持。不新增持久缓存，不修改共享 store、接口、字典、后端或资金命令。App/H5 按实际暖返回及异常恢复路径验收，源码测试和构建不替代实景。
