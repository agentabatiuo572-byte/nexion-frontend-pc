# UVEL 全站静默暖刷新（第一批）

已有同账号、同页面作用域的可展示结果时，只读刷新不插入“正在刷新”“保留上次结果”等可见文案，不把现有指标、按钮名称或钱包金额替换成加载说明。首次尚无结果的冷加载保留原占位；真实失败保留明确错误和重试，不宣称数据已更新。空列表的成功读取也属于已有结果。

本批覆盖首页收益卡、我的订单提示、信任中心、偏好中的通知管理、每周任务导航按钮、试用设备行、Genesis 抽签和概览刷新、链上提现事实展示、银行既有订单查询、回购历史查询、促销结算钱包展示。Team 与其他模块由各自独立增量覆盖。

- 我的与偏好仅记住本页当前作用域的成功读取；账号或绑定变化清除该标志，隐藏或已过时的请求不能为新作用域完成读取。不会增加跨账号缓存。
- 试用、每周任务、提现和促销支付在暖刷新期间继续使用原实时资格与命令保护。余额可见不代表当前可支付，提现旧事实可见不代表可报价或提交；任何真实资金读取失败继续显示失败，即使另一数据源仍在刷新。
- 银行静默仅适用于当前仍显示的既有订单读取；初次读取、配置表单、报价和提交保持原有加载及禁用状态。不会把未知金额写成零。
- 回购历史的独立暖读取静默；已确认操作后的历史同步反馈、提交、恢复、领取及支付进度保留。分页、用户操作结果、服务端到期与倒计时规则不变。

验收须覆盖中英越、成功空结果、已有数据暖读、冷读、真实错误与重试、账号/绑定切换、隐藏与迟到请求、以及刷新时按钮和命令仍拒绝。源码与行为测试不替代 TEST 页面和原生实景验收。

## 静态按钮在只读刷新期间保持呈现

每周任务导航、试用设备购买/取消、偏好清空已读、银行既有订单三操作以及促销钱包刷新，读取期间保留固定名称、箭头和原有对比度；每周任务固定导航名不改成读取文案。仅对读取状态作局部视觉覆盖，原禁用语义、键盘和点击守卫保留；目标关闭/过期、试用未知、取消中、确认清理中及其他真实命令/资格不可用继续采用原状态。整体任务卡是否存在依赖真实任务，不能凭空造任务。三处未知表单静态壳另有后续增量，不以本段宣称完成。

## 固定结构与未知数据分离

- 偏好六类通知的名称及图标常驻。首次未确认的开关用“—”占位，并以不可交互的分组及本地化未知说明表达；不得显示成“关闭”，不得具有开关已选值或指针/键盘切换。确认后的真实开关值、强制项锁定和更新失败反馈保持原规则。
- 回购的固定说明、字段标签、装饰图标、动作名称与历史标题常驻；未知余额、费率、期限、收益及历史用“—”，不补零。同作用域有效只读刷新可显示已有数据，仍以原 remoteReady、配置、余额及确认检查决定输入和操作资格；未知输入及档位直接拒绝。真实失败清楚提示并提供重试，未决操作的查询和确认后的历史同步继续保留。
- 银行新提现页在首次或失败配置读取时保留当前步骤的标题、说明和固定字段，收款人、银行及额度未知时仅占位，不默认通道或编造绑定状态。既有配置仅在当前同作用域只读刷新时作为展示投影，命令继续使用已清空后重新确认的原配置；失败、账号或绑定失效即弃用旧投影。已有订单及未决意图恢复保持独立原路径。

本增量不把真实资格、余额不足、输入错误、业务关闭或提交状态画成可用。表单未知与真实错误可能改变动态区域高度；固定结构常驻不构成资金资格或业务成功承诺。

## 银行展示投影的同步作用域隔离

银行配置展示投影只在真实配置读取成功并通过当前请求校验后，绑定该次请求的账号及绑定代次；新读取不得把旧配置重新标成新账号。账号或绑定变化立即同步清空页面状态和展示投影，再由原读取流程合并请求。同一时刻的返回页面、A→B→A、旧成功或旧失败都不能恢复先前收款信息；当前401/403或读取失败清楚显示错误，不使用旧投影。报价、提交、未决意图恢复及其真实资格守卫保持原规则。
