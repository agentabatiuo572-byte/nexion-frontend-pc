# 固定10秒被动读取（历史版本，已替代）

**本文件仅保留历史证据；当前有效规则见[五 Tab 快切保护：1秒内3次变化，3秒退出](../docs/PRD/UVEL_Tab快切保护_20261028.md)。以下固定10秒条款不再作为当前验收标准。**

日期：2026-10-28。用户最终确认 **10 秒**；此前 30 秒与 15 秒的 Tab 读取窗口均不再适用。

## 用户可观察行为

- Home、Earn、Team、Store、My 及其随 Tab 激活的子组件首次读取立即执行；同一资源、同一读取归属下，10 秒内快速切 Tab 沿用本轮已有结果，不因切换重复请求。
- 正在读取时只加入同一请求；10 秒从实际读取尝试开始计时，等待完成不会重置计时。普通失败也占用该窗口，避免来回切换造成失败请求风暴。
- 窗口结束不启动定时请求。下次展示页面时静默读取，维持既有展示、加载、错误与恢复规则。
- 用户点击刷新或重试可以立即重新读取；HTTP 429 的服务端 Retry-After 仍优先约束所有入口，显式 0 有效，缺省为 30 秒。此 30 秒仅是服务端限流兜底，与 Tab 窗口无关。
- 真实业务写入后失效相关被动读取上下文；手动读取成功或严格失败不会在下次切回时重新播放旧成功或旧错误。

## 读取归属与安全边界

窗口仅存在当前进程内，不持久化。归属至少包含账号与绑定代际、认证主体与真实会话链、API 环境与地址、语言、真实运行命名空间、业务写入版本；具体资源另包含其读取 owner、运行版本和查询参数。正常 token 刷新不构成新会话链。

注销、同号重新登录、账号切换、权限失效和真实 owner 失效不能复用旧读取；旧请求完成不得覆盖新 owner。页面和 store 原有当前账号、权限、请求代际校验继续执行。

窗口只限制显式被动展示读取。余额、价格、库存、设备权限、交易资格及业务动作前必要校验继续取得原有实时服务端依据；展示快照不授予操作资格。设备心跳、任务执行、WebSocket、可见性、时钟及浏览观测保留各自原有生命周期。

## 商品目录发布

相同已确认完整目录内容再次读取成功时，更新实际快照但不重复推进运行版本。首次、内容任一有效字段变化（即使 revision 未变）、严格失败后恢复、prepare 或外部运行版本失效后，仍执行原有发布与同步失效规则。所有价格、库存、可购字段、展示字段和来源字段均参与内容比较；失败、prepare 和外部运行失效撤销内容签名。目录历史展示仍仅为只读上下文。

## 验收

1. 预热五 Tab 和子组件后，在任一资源 10 秒窗口内快速切换，因 Tab 激活产生的额外 GET 为 0；分别统计设备心跳与实时通道。
2. 在 9,999 ms 不重复读取；10,000 ms 后下一次展示仅触发一次当前资源读取；长请求持续加入同一 pending。
3. 普通失败、429（0、显式等待、缺省 30 秒）、手动恢复、严格 401/403、账号/语言/环境 ABA、时钟回拨均保留原有安全边界。
4. 冷启动目录发布使并发旧 owner 读取失效后，当前 owner 可立即补读，不能因旧 false 占用窗口而停在加载态。
5. 静态或本地自动化通过不替代 TEST 真机请求计数与页面验收。

## 2026-10-28 真机递归入口补充

真实诊断包的四轮五 Tab 切换暴露了未统一的子组件/路由读取：页面本身命中窗口，子组件或路由回调仍调用手动刷新方法时，会失效同资源窗口并重新发请求。所有随 Tab 展示触发的后代组件、组合函数及页面观测前置读取，均使用与页面相同的资源窗口；用户点击重试仍使用原有实时方法。观测提交、设备任务与心跳的业务语义不因此改变。

平台配置的被动入口使用 `config.revalidate()`：加入现有启动配置请求，不能因为等待该请求而排队再读一轮。手动 `config.load()` 保留原有显式重读语义。公共配置只允许加入同环境、同 API 地址的启动请求；环境或地址改变后立即撤销配置依据，拒绝旧响应写回，并等待新运行实例创建相应 API client。Day-One 页面观测在任务读取尚未成功时，加入共享 `quest` 被动窗口；失败时不得在短时间内通过反复页面展示重新读任务，也不得凭空生成任务实例或提交完成。

请求计数按真实 transport 分别记录。一个领域读取可能包含多个 GET，例如 Genesis public state 同时读配置、挂单历史和交易历史；诊断去除查询参数后会合并为同一路径，须区分领域读取次数与真实 GET 数。新源码仍须通过 TEST 真机频切验收，自动化只提供定位与回归证据。

网络设备排名改为 `networkRank.ensure()` 统一被动入口，只使用从实际尝试开始的一个 10 秒窗口；不再叠加从成功返回开始计算的第二个窗口。手动排名读取保留实时刷新，正在进行的同归属请求可合并，HTTP 429 的 0/显式/缺省等待继续优先。环境、会话链、账号绑定、语言或业务写入归属变化后，旧排名请求不能覆盖当前结果。

同环境的公共配置启动请求在登录后仍可共享，但窗口保持最初真实发起时刻，不从登录或加入 pending 的时刻重新计时。环境依据取自实际创建 API client 时的不可变身份；仅重建页面或 store 不能把已变化的配置地址误当成旧 client 的新地址。
