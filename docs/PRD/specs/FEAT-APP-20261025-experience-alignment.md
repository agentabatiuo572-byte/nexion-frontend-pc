### F1 等级奖励内容与配置变更（2026-10-26）

配置变更仅作用于后续按现有服务端规则判定的晋级及奖励处理，不追溯重算已发记录、不自动向历史已晋级用户补发，也不通过人为晋级触发验收。历史流水保持；配置保存、公开规则展示和客户端显示均不能代替真实奖励入账证明。资金奖励编辑与发放继续受现有权限、确认及服务端执行校验约束。

## H9 首页数字增长

独立板块“首页数字增长”同时包含在线设备当前值、累计已发放当前值及两组每秒区间；开启/暂停按钮与状态放在该板块头部。保留 `growth_h9_write` 写权限及既有确认、理由、审计、版本冲突检查，只读人员不能修改。

用户指定介绍页在线设备从 28,432 开始，每秒增加 1–3；累计已发放从 $130,532 开始，每秒增加 $1.10–5.50。默认暂停，只有点击开启并确认才开始增长。暂停保存当时数值，恢复继续增长；普通保存不隐式开启。

| 字段 | 合法域 | 初始值 |
|---|---|---|
| `H.publicStats.homeOnlineCurrent` | [0, 9000000000000]，整数 | 28432 |
| `H.publicStats.homeOnlineStepMin` | [0, 1000000]，整数 | 1 |
| `H.publicStats.homeOnlineStepMax` | [0, 1000000]，整数 | 3 |
| `H.publicStats.homePaidCurrent` | [0, 9000000000000]，最多两位小数 | 130532 |
| `H.publicStats.homePaidStepMin` | [0, 1000000]，最多两位小数 | 1.10 |
| `H.publicStats.homePaidStepMax` | [0, 1000000]，最多两位小数 | 5.50 |

两个区间均要求最小值不大于最大值。到上限停止增加。

后端每分钟扩展一次全平台共享的随机批次，真实随机、不固定种子。批次持久化数据库，Redis 缓存 60 秒；H9 修改与生成批次使用同一版本行锁。客户端只拉取公开的批次和服务端时间，不接受用户写入；每 60 秒刷新，页面隐藏停止本地更新，返回立即重新拉取。状态修改最多 60 秒同步到已打开页面。查询失败显示占位，不继续播放旧批次。

长时间后端停机超过预生成窗口时，恢复从最后持久数值继续，不补造停机期间的随机增量。两个数字仅用于首页展示，不改变真实设备、账单、余额、奖励或统计报表。

本补充替代旧规格中介绍页从设备日产锚推导支付额的规则；历史参数仍保留兼容，其余业务统计不受影响。批次接口为 `/api/config/home-display`，金额以整数分传输。


补充状态与性能契约：

- `H.publicStats.homeDisplayEnabled` 为开关，默认 false；保存六项配置不隐式开启。字段组完整提交，区间 min≤max；只改区间而未显式改当前值时接续已增长值。按钮操作沿用保存确认链，不绕过脏表单校验。
- 批次覆盖 120 秒、含起点 121 个累计值；客户端按服务端时间读取同一序列，因此同一时间索引一致，不由各客户端独立随机，也不承诺逐帧同步。
- 每分钟生成/续接全平台一份批次；Redis 用作 60 秒缓存和防旧序列覆盖，数据库保存批次与锚点。不是每用户每秒任务，也不是 Redis 内每秒定时器。
- 页面进入/恢复时读取，持续可见时约每 60 秒或到期刷新；仅可见时本地 1 秒更新这两个数字，隐藏/离开停止，变化值才触发界面刷新。退出后重进按当前批次显示，不重置种子或初始值。
- 批次无效、过期或查询失败显示“—”，不继续旧序列、不外推；配置变更最多 60 秒同步到已有页面。
- 首次迁移只对未配置开关的环境写入用户指定起始值与暂停状态，重复执行不重置运行值。迁移文件为后端 `scripts/manual_migrations/20261025_team_v8_home_display.sql`。
