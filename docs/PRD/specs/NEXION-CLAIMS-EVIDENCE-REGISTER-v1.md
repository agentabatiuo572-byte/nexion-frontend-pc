```text
  monitoring/              # 真实性指标、失效阈值、告警与撤回演练

```

证据强度从高到低：主管机关/公开审计原件 > 已签合同与生产记录 > 权威账本/可复算数据 > 内部设计文档 > 口头说明。低强度证据不得支持高影响绝对声明。

## 4. 发布与撤回闭环

1. 内容创建人选择声明 ID，不允许自由复制高风险数字或品牌名。
2. 系统检查地区、渠道、语言、有效期、证据哈希和批准状态。
3. 法务只批准法律边界；技术/财务分别对事实和数字负责，任何一方不能替代另一方。
4. 发布候选中全量扫描关键词：`MSB|MiCA|Chainalysis|PwC|Sumsub|SOC 2|FDIC|SIPC|APY|年化|收益|保证|上所|限量|最快|监管要求|独立审计|储备|零知识|国家|证件`，扫描 App、H5、PC、官网、客服宏、推送、广告和商店元数据，结果逐条映射本台账。任何未映射声明默认阻断发布，不能由关键词白名单静默放行。
5. QA 保存首屏、详情、条款、商店元数据、推送和客服话术截图，绑定 commit/Build ID。
6. 每日检查到期与真实性指标；证据失效、供应商终止或统计超差时自动撤回并生成审计事件。
7. 撤回后检查缓存、CDN、旧版本远程配置、三语资源、广告素材和客服宏，不能只改一个页面。
