# Store 升级图片签名续期与已解码展示（2026-10-27）

## 功能与范围

Store 升级卡的基础设备、目标商品照片继续由当前商品目录提供。图片能否展示与价格、库存、报价和购买权限无关；照片保留不能授予购买资格。

同账号、绑定、图片角色、SKU及同一可信不可变媒体对象的已解码照片，在目录暖刷新以及 URL 的 signature/expires 续期时保留原图片节点与已解码状态，不先变回中性占位。仅现有公共版本媒体缓存规则认可的 HTTPS 对象、且查询参数恰为单个 signature 与单个 expires 时，续签可视为同一图片。任意额外查询参数、重复参数、其他URL规则或对象变化均按新资源处理，不以忽略全部查询参数的方法合并图片。

未完成解码或已经失败的图片不继承成功状态。续签时使用当前新URL重新解析；真实 load 成功后才标为 ready。真实 decode/error 仍处理为失败，保留现有本地坏缓存的一次重试；后续目录确认 ready 可以按该侧 refreshKey 重试相同URL。另一已成功图片不重建。签名过期不使仍属于当前请求的 error 事件被忽略。

账号、绑定epoch、角色、SKU、不可变对象、非续签URL变化或图片撤销，立即移除旧帧并等待当前图片真实解码。被替换、失败、卸载owner的迟到 load/error 和旧native解析不能改变新请求。真正组件卸载再挂载仍需新节点解码，不把上一owner的 ready 转移给新节点。本补修不引入全局已解码缓存或持久缓存框架。

## 独审退修：续签后的错误恢复与合并读取

- 保留已解码frame不表示继续使用捕获的旧签名。若接受新签名后当前图片发生真实error，既有一次本地坏缓存恢复读取当前已接受的URL；旧签名过期仍不影响此选择。恢复pending或新frame未收到真实load时保持失败/加载状态，旧load不能将其冒充成功。重复失败不自动无限下载。
- 公共不可变图片的进行中下载仍按对象合并。成功本地文件路径可共享；HTTP/网络失败返回远程URL时，每个调用者分别使用其请求的当前URL，不能继承第一个合并请求的旧签名。后续显式刷新可再按当前URL恢复。该缓存仍不提供账号、商品或购买授权。
- 独审以真实product-image-cache和受控uni文件下载复现以上两项，原probe保留。补修增加同样真实cache的实际SFC回归，覆盖最终新图decode与失败不循环；真机67ms事件仍待root复验。
