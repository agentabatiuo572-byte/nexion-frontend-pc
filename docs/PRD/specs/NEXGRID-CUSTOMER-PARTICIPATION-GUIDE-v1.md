# NexGrid 参与方式与新手问答

适用范围：App 用户可见的参与条件、奖励用途、提现与状态查看。

## 场景 01

问：我该怎么赚钱？

答：在 NexGrid，可以先了解设备任务和当前开放的任务或活动，再分清分享与奖励的区别；参与并不代表一定赚钱：

1. 设备任务收益：设备满足运行和任务条件、完成相应计算任务后，按规则形成收益；拥有设备不等于已经激活或已经入账，要分别看设备状态、任务进度和结算记录。
2. 任务和活动奖励：在任务中心或活动页查看参与条件、完成要求、截止时间和领取方式；完成任务与奖励入账可能是不同阶段，奖励也不一定是可提现现金。
3. 邀请与分享：App 的分享邀请链接用于帮助朋友了解产品，当前没有启用的推荐奖励，不按发展下线计酬；不能把分享或邀请视为当前赚钱途径。

如果账户有免费试用资格，也可以先了解试用条件；试用抵扣金不是可提现余额，不会因为开始试用就直接增加钱包余额。具体奖励、条件和结算以 App 当前页面与记录为准。

你现在是刚注册，还是已经拥有设备？

## 场景 07

此前问题：不购买不邀请能赚钱吗

问：那怎么开始？

答：可以按下面的顺序开始。你选择不购买、不邀请，可以先筛选符合这些条件的任务或活动；如果当前没有符合条件的活动，就不能保证有奖励可领。

1. 先进入任务中心或活动页，挑选你感兴趣的任务，优先查看不要求购买的项目；跳过要求邀请或推广的任务；
2. 打开任务说明，核对参与资格、完成要求、期限及奖励用途，符合条件再按页面步骤操作。
3. 完成后查看是否还需要领取，以及奖励记录的处理状态；奖励可能是券或其他权益，不一定能直接提现。

## 场景 08

问：钱怎么拿出来？

答：你是想把 NexGrid 里的资产转出。可以先查看 App 钱包的可用余额，再进入提现页核对可提金额；试用抵扣金、预估收益、未结算奖励不等于可提现余额。

提交前请核对币种、收款地址或收款方式、网络、费用、安全验证，以及单笔限制和今日剩余额度。提交成功不等于收款方已经到账，之后可以查看提现记录，不要重复提交同一笔需求。

## 场景 09

问：为什么没收到？

答：要先确认是哪一笔：充值、提现、设备收益，还是活动或邀请奖励？这些款项的查看入口和结算条件不同，单凭“没收到”还不能判断原因。
