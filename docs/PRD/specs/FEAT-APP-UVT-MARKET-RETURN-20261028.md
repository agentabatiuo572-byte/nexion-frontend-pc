# App UVT 钱包至行情的保栈返回

日期：2026-10-28。范围：App UVT钱包“查看行情”的只读导航与返回。

## 来源与条款

来源为 App `PRD/NexGrid_产品功能架构设计文档_v3.7.md`，§9.9.2“页面结构”中的 Hero / View market 条款（源行2982，章节起始行2975）。冻结源树 `181d3ec12d1a97639d70663c7f164f45730aa9e2`，该源整文件 Git blob `4082be6ea5b50b4c20e415762fed25f316264638`。下文仅摘录该新增条款，未复制整份App架构文档，也不替换PC主架构或钱包资金规则。

```text
   - `View market →` 链 `/market`，按普通子页压栈保留钱包入口；行情顶部返回及原生系统返回优先回到原钱包页面并保留原滚动位置，余额继续按钱包原有权威读取更新。只有无上一级页面的行情直达/冷开，才沿用首页返回目标；不以清栈打开行情，不改变买卖方向、报价或交易资格。
```

UVT为当前界面平台币名；源文档既有NEX命名与`/market`路径按原文引用，不改变资产标识或金额。余额仍由原钱包权威读取更新，买卖方向、报价和交易资格不因保栈返回变化。

## 验收边界

实际从钱包进入行情后，顶部返回和原生系统返回应回原钱包及原位置；无上一级的行情直达/冷开仍回首页。源码、文档同步与哈希一致不代表真机/H5已验收；本次文档同步不执行交易或发布。
