# 签到详情只读入口

补充[设计审查功能同步 F01](https://github.com/agentabatiuo572-byte/nexion-frontend-uniapp/blob/1f5862110c904749bfc71f41e1dfc479a3b257a1/PRD/UVEL_%E8%AE%BE%E8%AE%A1%E5%AE%A1%E6%9F%A5%E5%8A%9F%E8%83%BD%E5%90%8C%E6%AD%A5_20261026.md)的首页、任务与签到合同。独立钱包退役后，每日签到详情、连签权益、规则和历史仍须可查看；不要求先完成当日签到、领奖、抽奖或连签恢复。

- Home 与 Missions 使用同一签到卡。标题和说明组成固定的“查看签到”链接，始终进入现有每日签到页；名称复用现有中英越 `viewDaily`，支持触摸、鼠标及 Enter，提供可见焦点及至少44px热区。键盘行为使用平台既有链接语义，Space 保留页面滚动，修饰键与按住连发不激活；组件不另设键盘处理。
- 入口在未签到、已签到、首次读取、暖读、读取失败及签到提交中保持可用，不因读取状态替换成另一行或改变标题/说明的业务含义。它只导航，不调用签到、领取或恢复操作，也不把展示快照当写入授权。
- 右侧签到按钮保持原单次签到操作及权限、资格、防重入、失败反馈；已签到或状态尚未确认时继续原详情恢复导航。不把整个父卡设为可点击，避免点击签到按钮同时触发详情导航。
- 页面隐藏后旧回调不导航；进入详情不自动提交任何奖励操作。返回沿原页面栈保留来源与已有位置，不恢复已退役的独立钱包或复投页。

本增量与禅道#672官方权益名称翻译、旧#164任务中心三卡无障碍语义分别跟踪。本地源码测试不代替App/H5真实页面验收；验收允许只读标题→详情→权益/历史→返回，禁止为了进入详情而签到或领取。
