# App 首页任务名称展示（2026-10-29）

## 需求与入口

用户反馈首页动态与收益流水仍出现 `TEST_DETERMINISTIC_V1` 和 `UVEL TEST deterministic`。首页动态、动态卡收益标签、收益流水及网络在线客户、算力市场共用后端首页展示投影；客户界面不展示这些内部执行名称。

## 展示约定

只对已知内部名称做精确展示映射：

| 原内部名称 | 客户可见名称 |
| --- | --- |
| `TEST_DETERMINISTIC_V1` | `Vector statistics` |
| `UVEL TEST deterministic` | `UVEL Compute` |
| `UVEL TEST vector statistics v1` | `Vector statistics v1` |

三语页面沿用同一任务/执行方专名；不新增工程说明或替换成未经执行的商业模型。普通名称保持原样，不按包含 TEST 的子串做全局删除。

所有首页任务/执行方名称的展示出口使用同一映射，覆盖已结算历史记录及后续同类记录。页面刷新或重新进入后仍生效。空数据、加载失败、重试和账号隔离继续遵循既有规则；不因名称清理删除记录或伪造空流水。

## 数据与业务边界

- 原始任务名称、执行类型、证明、回执和审计数据保留。仅首页输出的客户可见名称变化。
- 任务/流水主键、金额、完成时间、排序、余额、收益汇总和结算规则不变，不重算或重放任务。
- “查看全部”进入资金账单，按已有本地化业务类型显示“算力任务收益”等名称，不使用内部任务 remark 作为展示兜底。
- 本轮只进入 `test` 和 TEST 环境；没有本轮 main 合并或生产发布批准。
