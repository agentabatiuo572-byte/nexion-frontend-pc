# H9 网络脉搏注册用户跳动（2026-10-28）

交接 03 UI-05。App 自 10/25 起按「起跳值 + floor((当前时间 − 起点) / 跳动间隔) × 每次增加人数」显示网络脉搏注册用户，并在缺少这组参数时隐藏整块；本补充把参数交给 H9 维护。

| 字段 | 合法域 | 说明 |
|---|---|---|
| `H.publicStats.registeredUsersBase` | [0, 100000000]，整数 | 起跳值，沿用原注册用户基数 |
| `H.publicStats.registeredUsersTickIntervalSec` | [1, 86400]，整数 | 跳动间隔（秒） |
| `H.publicStats.registeredUsersTickStep` | [0, 100000000]，整数 | 每次增加人数，0 表示保持不变 |

- 跳动间隔与每次增加人数成对保存，只填一项不能保存；未设置前公开接口不下发这组参数，App 不显示该块，后端 `networkPulse.registeredUsers` 继续按月增长率推算。
- 修改起跳值、跳动间隔或每次增加人数，服务端把起点重置为保存时刻，数字从起跳值重新开始；其他字段保存不移动起点。已设置的跳动参数不能清空，只能改为新值。
- 公开接口只多下发起跳值、起点、跳动间隔、每次增加人数四项，其余运营参数仍只在管理接口。该数字是展示用推算值，不是注册统计，不改变真实账户和设备预估排名。
- 后端：nexion-backend `GrowthPublicStatsService`（PR #21）。旧版后台不传这两项时保留已保存值。
